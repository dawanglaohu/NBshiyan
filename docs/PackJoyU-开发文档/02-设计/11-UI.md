# UI

前台采用 `brand` 寄存器，以品牌、产品影像与询盘为中心；后台采用 `product / back-office` 寄存器，以账号、咨询对象和真实统计为中心，共用 `minimalist-flat` 的唯一视觉 token，后台按本节密度组织列表、表格与表单。

本节规定目标取值和验收要求，未实现产品页面或修改样式。页面范围与第07节的23个路由模式一致，`[locale]`仅为已发布的en/ru；聊天浮层、看板分区和恢复步骤不另增路由。现有条件上线、权限、noindex与内容完整度规则继续有效。

## 视觉方向

### 寄存器与风格

`brand`为全项目主寄存器；后台是同一品牌下的`product / back-office`。前台采用影像与产品主导的信息层级，后台采用批量业务对象的扫描和处理结构，不在后台复制品牌首页的巨幅标题、展示留白或视频区域。

`minimalist-flat` — 以黑白平面、清楚边界和单一强调色承托生产视频、包装与3D，前后台共享方向，页面按用途分配密度。

唯一目录原件为`_run/stylekit-spec.json`，slug、目录返回值和来源保留原样，实施与审查继续使用该文件，不重新搜索或更换slug。目录类名只是取值来源；项目沿用现有CSS和原生控件，不引入Tailwind、组件库或新字体包。

### 目录原值与可用范围

| 项 | 目录原值（原样） |
|---|---|
| palette | `primary: #000000`；`secondary: #ffffff`；`accent: [#ff3366, #00d4aa, #ffcc00, #b45700]` |
| type | `heading: font-bold tracking-tight`；`body: font-sans`；`mono: font-mono` |
| sizes | `hero: text-4xl md:text-6xl lg:text-8xl`；`h1: text-3xl md:text-5xl`；`h2: text-2xl md:text-3xl`；`h3: text-lg md:text-xl`；`body: text-sm md:text-base`；`small: text-xs md:text-sm` |
| border | `width: border-2`；`color: border-black`；`radius: rounded-none`；`style: border-solid` |
| interaction | `transition: transition-colors duration-200`；`active: active:opacity-80`；`hoverOpacity: hover:opacity-90` |
| layout/spacing | `section: py-16 md:py-24 lg:py-32`；`container: px-4 md:px-8 lg:px-16`；`card: p-6 md:p-8`；`gap.sm: gap-4 md:gap-6`；`gap.md: gap-6 md:gap-8`；`gap.lg: gap-8 md:gap-12` |
| signature | `Strict 2D Flatness`；`High-Contrast Inversion`；`Instant Sharpness` |

目录globalCss中的变量原值为：

```css
:root {
  --minimalist-flat-primary: #000000;
  --minimalist-flat-secondary: #ffffff;
  --minimalist-flat-accent: #ff3366;
  --minimalist-flat-glow: rgba(0, 0, 0, 0.3);
}
```

目录button recipe的base为`font-medium`、`border-2 border-black`、`transition-colors duration-200`；primary为`bg-black text-white`，secondary为`bg-white text-black`，outline为`bg-transparent text-black`；hover为`hover:bg-white hover:text-black`，active为`active:bg-gray-100`，disabled为`opacity-40 cursor-not-allowed`。目录card base为`bg-white`、`border-2 border-black`、`transition-colors duration-200`，仅显式给出`hover:bg-black hover:text-white`。目录input base为`w-full`、`bg-transparent`、`border-0 border-b-2 border-black`、`text-black`、`placeholder:text-gray-500`、`focus:outline-none`、`transition-colors duration-200`；focus为`focus:border-[#ff3366]`，disabled为`opacity-40 cursor-not-allowed`。完整size、variant与slot仍以原件为准。

HTTP获取标记为`_stylekitSource.kind=http-api`、`degraded=false`，`provenance.source=static`、`contentHash=fnv1a32:63054a3b`；这是获取成功记录。`readiness.source=fallback`，仅`themeModes=[light]`，`darkMode.support=missing`；default/hover/focus-visible为complete，active/disabled/loading/skeleton/empty/error/success为partial；motion与accessibility为partial，performance为fallback。该数据不能证明项目全部状态、对比度、媒体、键盘或俄文字形已经验证；本轮只交付浅色UI，黑色反色区域不构成暗色主题。

原globalCss含gradient、frosted、半透明伪元素及位移动画，和目录禁用项冲突；recipe的disabled opacity-40与“不低于0.5透明度”冲突，active灰底也与纯色限制不一致。完整globalCss及@apply不得直接注入项目。下列项目适配统一使用纯色、无阴影、无模糊、不透明禁用状态和稳定几何；以明确状态表补足partial项，不把补充值声称为目录原值。目录给出的营销间距不进入后台，间距以本节独立契约为准。

### Palette（项目适配）

`background #ffffff`用于页面、表单和模型工具条；`foreground #000000`用于正文与数值；`border #000000`用于2px边界；`inverse #000000 / on-inverse #ffffff`用于主按钮及反色区；`accent #b45700 / on-accent #ffffff`用于当前入口、聚焦边界、错误/警示文字与明确操作反馈。强调色取自目录允许列表，不叠加第二色板。状态含义同时用文字、图形或边框样式表达，不靠颜色区分。正文不使用半透明黑；必要的次要层级用字号、字重和位置表达。

### Type（项目适配）

display/body/utility沿用项目现有Manrope的`--font-sans`（既有latin/cyrillic配置），后台未持有该变量时回退`Arial, Helvetica, sans-serif`；数值/时间使用`ui-monospace, SFMono-Regular, Consolas, monospace`，不新增下载字体。英文/俄文正文16px/24px、400；后台表格14px/20px、400，标签14px/20px、600，辅助文案14px/20px、400；按钮14px/20px、600。前台hero为桌面64px/68px、窄屏36px/40px、700；前台h1为48px/52px→32px/36px，h2为36px/40px→28px/32px，h3为24px/28px→20px/24px；后台h1固定28px/32px、700，h2固定20px/24px、700。标题tracking=-0.02em，正文tracking=0；俄语不强制大写、不截断必要标签，字体缺字时落系统栈。

### Layout（项目适配）

前台以“清楚标题 + 有边界的真实媒体/产品区 + 直接联系入口”组织，标题不压在动态画面上；后台以固定导航、紧凑标题/筛选和铺满可用宽度的工作区组织。全站4px基础刻度、2px实线、0圆角、0阴影；只有媒体自身有透视与3D，UI不借位移、缩放或渐变制造层次。

### Signature（项目适配）

保留现用PackJoyU字标的形状和比例，以2px黑线框住大幅产品/媒体视口，交互通过黑白反转与#b45700边界提示完成；让包装轮廓和操作空间成为识别点，不重画字标、不做几何hover缩放。
