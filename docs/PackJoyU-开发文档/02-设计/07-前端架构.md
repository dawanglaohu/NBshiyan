本节是目标代码组织约束，尚未实现本轮功能。源码事实基线为 `971b5b46faa0c468fc85372773de612bebd51c3c`，完整既有页面来自本轮规划证据 `_run/source-map.md`与`_run/source-map.json`，其`entrypoints.pageRoutes`为既有路由来源（下文简称sourceMap）；以第01/02/05节、冻结的第06节职责和第10节接口为范围。本节确定组织、接口与交互状态归属；视觉取值由第11节唯一规定，不在此复制另一套值。

下树的既有入口按实际路径保留；标“新增”的目录/文件是实施落点，不是当前源码存在性声明。`src/styles/tokens.css`已经存在，由M1按第11节规定值，后台消费同一源；各域CSS只写布局和语义状态，不能另起视觉token。

## tier

page/layout负责服务端数据和守卫，container/hook负责请求、状态及取消，展示组件只接DTO与事件，ui只包装原生控件；禁止展示组件直接fetch、client导入server/Prisma、页面跳过服务端权限或业务组件绕过ui重复造通用控件。

| 层级 | 本项目责任 | 可调用与禁令 |
|---|---|---|
| page/layout（Server Component） | 获取公开目录/已净化about数据、metadata、locale及当前后台角色；后台页面执行enforceAdminPage；仅将安全DTO交客户端 | 公开内容可调用现有server读取函数；后台不得只依赖layout检查；不能把User实体、sid凭据、tokenHash、环境配置作为props下发 |
| container/hook（Client Component） | 组合api模块、useReducer/useState与AbortController，提交/取消/失效/草稿/轮询；模型container接收真实加载事件 | 可调用客户端api模块及Auth.js客户端；不可直接调用server repo、拼新endpoint、忽略卸载回调或把副作用放展示render |
| 领域展示组件 | SourceCard、MessageList、DeviceRow、LoginForm字段、ProductCard只消费DTO/状态与onSubmit等事件 | 不fetch、不读process.env、不把role隐藏当授权；消息一律纯文本，不将bodyText送dangerouslySetInnerHTML |
| ui包装 | 原生button/input/dialog语义、焦点、disabled/busy及错误关联；视觉值消费M1 token | 不决定是否允许重置账号、采分析或操作会话；不为每个域复制通用表单控件 |

现有about正文继续只渲染读取服务已净化的`bodyHtml`；不能把聊天或PDF内容借该出口当HTML注入。新API请求和响应schema来自`src/lib/contracts/index.ts`，不从Prisma模型推客户端类型，也不在组件手写同名DTO。旧询盘/邮件/设置仍用原API入口，未触及部分不迁移信封。

## ui

沿React19、现有CSS和原生HTML，通用包装置src/components/ui，领域组件留原域；复用现有焦点/对话框能力，只有已有控件不覆盖的语义才增原生包装；禁止新增组件库、状态库或在领域组件另选slug/色值，第11节统一写现有token文件。

语义包装先复用现有`src/lib/a11y/focus.ts`、后台focus-trap/drawer和已存在的对话框行为，再将本轮重复控件收在`src/components/ui/`。只有原生语义不能表达、且05已有能力可直接满足时才在原域补组件；不引入Radix、shadcn或另一套图表/表单库。数值趋势先用React与SVG/表格呈现同一DTO；不能为图表选型扩大05栈。共用token取值、断点、卡片尺寸、密度、媒体位置和键盘细节交第11/12节，不在本节提前裁定。

### 加载、守卫和路由边界

登录页在`src/auth.ts`的Auth.js `pages.signIn`接入`/admin-login`；`/api/auth/signin`原入口和CSRF/redirect协议继续有效，既有`adminLoginHref`仍可经它到自定义页。新的登录/恢复root layout与既有admin-enroll消费同一token和语义控件，均noindex、no-store、no-referrer；`next.config.ts`安全头覆盖两条新增路径。受限恢复不使用ADMIN角色布局，也不从page读取cookie路径外的受限凭据，只让第10节recovery API验证其HttpOnly cookie。

登录模式只用第10节和account schema的`password`/`totp`枚举。日常页面以“账号+验证器码”为默认方式，并有“密码登录”入口；只有本人已启用的账号才允许totp模式，未知/未启用账号均通用失败，不增加账号方式查询API。缺mode保留旧password+totp请求；rememberDevice表单受控Boolean经Auth.js传输时仅接受第10节的字面true/false规则，不能`Boolean('false')`强转。个人信息启用开关后重新登录以totp方式呈现，未绑定者走首次绑定而非批量强开。

新后台page设`force-dynamic`、`enforceAdminPage`与服务端当前角色；后台导航只是体验层。`prefetch=false`用于新增敏感后台入口，不能预取本角色不可见的内容。公开目录与about保留既有SSR/60秒/tag失效，公开入口跟随真实可见性；动态模型/聊天不扩大整页Client Component边界。

`GalleryScene`维持`next/dynamic`的客户端分包；海报/标题/询盘入口先SSR，Canvas只在产品相关路由且可见时按需挂载，PC视口内可直接按下操作。退出产品页释放监听/计时器/交互捕获，不把整个站点包引入Three。访客聊天窗口在主动点击入口后加载客户端包，后台聊天与看板按路由分包，关闭浮层/隐藏标签页暂停轮询；没有新增WebSocket/SSE。`/[locale]/s/[id]`仍是sourceMap确认的共享设计占位，本轮不接其定制设计预览或新增设计编辑功能。

产品输入由`ProductGallery`及同域`use-product-interaction.ts`统一持有，状态为未操作、加载、可操作、正在操作、回退；`GalleryScene/OrbitControls`只消费当前activeSlug和回调，不再各自依靠悬停计时争夺滚轮。PC悬停可显示提示，实际按下拖动或“操作3D”才进入操作，pointer capture只属于当前模型；操作时暂停自动旋转，拖动不触发卡片跳转/加入询盘。普通滚轮始终交给页面；只有模型已聚焦且Ctrl/Cmd+wheel，或用户点明确缩放控件时才缩放模型，其余情况滚动页面；pointercancel、退出、Esc、失焦和卸载都释放捕获，触屏退出后恢复页面滚动。可见“完成/退出”“复位”及已有开盖/刀模按钮走同一状态机，键盘无需拖动也能查看与询盘；卡片名称/动作独立于Canvas点击区域，减去重复介绍不删除必要名称和操作。尺寸、触控阈值及反馈文案由第11/12节规定。分析事件从真实已发布条目的查看/模型发起及最终成功/失败回调产生，导航只记录page_view；品类slug不能未经映射就冒充单产品或GLB加载成功。

## api

新请求由src/lib/client/api.ts及account/chat/analytics/ops客户端模块消费10节DTO，15s AbortController、same-origin/no-store，兼容旧{error}；Auth.js仍用原CSRF/signIn/signOut协议；只对10节允许的消息写复用UUID退避重试，禁止自动重试一次性授权/恢复/CAS写或新增便捷endpoint。

`src/lib/client/api.ts`实现相对站内路径、`credentials: same-origin`、JSON限体结果解析、15秒截止、调用方AbortSignal合并、`cache: no-store`及受控错误归一。`api-errors.ts`接受新`{error,requestId,fieldErrors?}`和旧守卫`{error}`；成功直接解析有名DTO，不要求`ok/data`包装。Abort由用户离开触发时静默结束，不显示服务故障；超时标“结果待确认”，不能把一次性写重复发送。Auth.js请求由其客户端维护CSRF/redirect/cookie，不经过统一JSON成功解析器。

| 客户端落点 | 唯一接口来源与动作 | 状态更新/重试 |
|---|---|---|
| lib/client/account.ts | 第10节account、activity、reauth、login-mode、devices/revoke、logout-all；旧password/2fa/reset兼容端点 | 账号/设备写成功读安全状态或重新登录；一次性授权不自动重试；GET取消与显式重读，不在每次render重复取 |
| components/admin/auth与lib/client/recovery.ts | Auth.js兼容族、既有enroll/confirm、新recovery/start/enroll/confirm；LoginMode只导入account schema定义 | 不增账号查方式endpoint；凭据提交无自动重试；重绑成功等待下一验证码步后正常signIn |
| lib/client/chat.ts | 第10节chat/session、conversations/message/read，admin/chat列表/正文/message/read/status | 首次消息与后续消息每个真实动作生成一个UUID；网络/408/429/5xx按1/2/4秒最多3次，原payload/key不变；轮询采用独立3秒/退避策略 |
| lib/client/analytics.ts | 第10节consent、events；只接01/09确认的白名单事件 | consent响应确认后发分析；批1..20，同事件重试不换ID；拒绝/撤回立刻中止在途后续采集，403停采，不把失败时间改成当前重发 |
| lib/client/ops.ts | 第10节stats、settings/analytics；只读安全来源，时区ADMIN写 | 手动刷新是GET；CAS409显示最新配置并保留本次选择供人重新确认，不自动PATCH，不访问cron/ops-report |
| 既有lib/admin与InquiryWizard | sourceMap记录的既有询盘、邮件、about/org、用户管理原接口 | 未触及契约保持；新恢复按钮只用第10节recovery-authorizations，旧直接reset-2fa旁路不继续调用 |

401一般受保护请求清内存、取消轮询，安全站内回跳到登录；`action_grant_invalid`停本次敏感动作，丢弃grant并重新本人验证，不误当完整会话失效。访客聊天401/404停止旧线程、保留当前内存草稿并提供“新咨询”，不能自动把旧消息重发到新对话。403/404/幂等冲突/已关闭/已匿名化不重试；幂等冲突保留原草稿供排查，不能偷偷换UUID强行提交。429尊重Retry-After并禁用该次发送直到可重试；`received`一旦确认，通知失败独立展示，不恢复成未发送。

密码/恢复等一次性写超时后，只有安全DTO能确认的状态才通过GET核对；无法确认的结果引导重新登录或独立恢复，不新增“查找旧秘密”接口、不重放已消费授权。页面离开时取消客户端等待不等于回滚已提交事务，不能因此回报操作已撤销。

## utils

无IO纯函数留src/lib/client纯转换模块及既有lib/a11y、three、quote、chat/rules、analytics/rules；seq合并/日期标签/字段显示可纯化；禁止utils读取env、发请求、持有当前账号/草稿、决定权限或把浏览器本地午夜当站点统计边界。

纯函数可处理`mergeMessages`、read上界裁剪、受控字段名、日期标签、媒体状态转换和模型取景数据；它们的输入显式包含所需时间/DTO，不读全局当前用户。实际fetch、cookie、浏览器监听、授权、同意准入和时区边界运算属于client hook或server职责。看板日期控件发送YYYY-MM-DD及所选revision，服务端根据站点IANA时区返回边界/口径；前端只按返回timezone标注，不用OS本地时区或固定24小时重算“今日”。

### 会话持久化的真实前端链

`AdminShell`挂载`AdminSessionActivity`，只在页面可见且实际鼠标/键盘/路由操作后触发第10节`POST /api/admin/account/session/activity`，按第09节节流15分钟并保证单在途；用户恢复可见后仍须实际活动才发。仅展示页面、后台聊天/看板轮询、定时器、无参`auth()`或读取session不续活动。响应的有效期限用于UI提示，真实续期必须由Auth.js适配层在HTTP Response写JWT/cookie；禁止只改React expires标签或调用session.update当持久化修复。

验证从“记住此设备”勾选/不勾选→真实Auth.js登录→后台可见活动控件→activity请求→浏览器cookie更新→关闭/重开后当前权限→撤销/超期拒绝串联。记录初登、activity及signOut的实际Set-Cookie与cookie有效期（用浏览器网络/上下文验证，JS本身读不到HttpOnly/Set-Cookie）；SSR只读路径不可宣称已写浏览器cookie。覆盖普通2小时活动滑动、记住7天闲置/30天绝对；达到任何期限、撤销、禁用或sv变化均清理/拒绝，轮询不能复活。普通退出当前设备无需新鲜本人验证，signOut服务端必须撤销sid；退出其他设备/全部设备遵D14授权。
