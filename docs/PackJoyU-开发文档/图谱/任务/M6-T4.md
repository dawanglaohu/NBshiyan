# M6-T4　交付可导航的核心数据看板页面

- 所属模块：[[M6]]　业务与运维看板：负责按角色查询并解释统计结果，读取询盘、聊天、接口错误、邮件、存储和备份的真实来源，区分数据时间、零值、无数据、未接入、失败和旧值。
- 前置依赖：[[M6-T6]]、[[M3-T7]]
- 完成后解锁：[[M6-T7]]

## 输入 / 产出

- **输入**：stats-core、后台壳、07页面入口与11样式密度
- **产出**：stats-base-ui；后台stats-link、日期/产品/刷新与核心指标页面

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 真登录后点击后台壳stats-link到/admin/stats
日期/产品/刷新控件发真实GET /api/admin/stats并渲染对应core DTO，授权浏览器/PV/产品/3D有真实来源，样本数与时区标签可见（[[E-61]]、[[E-63]]）。2) ADMIN/SALES/EDITOR页面仅呈其权限来源，直接请求越权仍403且响应不含隐藏计数
1920×1080、1440×900、390×844以真实会话留GIF与density=7/gutter16/gap16/pad16报告，work面按D1-D6且手机保留真实n/a（[[E-66]]）。

## 必须处理的边界

- [[E-61]]　运维指标扩展及角色权限
    - 触发：本轮验收今日授权访客、PV、产品归因与 3D 查看/加载指标
    - 期望：列出一轮真实产品动作证据：同意→实际页面/产品访问→实际 GLB start/terminal→真实五分钟作业提交→看板读取真实日/产品聚合，逐项核今日授权浏览器、PV、归因和3D指标。核心来源不得以未接入或固定值交差。
- [[E-63]]　运维指标扩展及角色权限
    - 触发：3D 加载有成功、失败、超时或没有样本
    - 期望：引用09节既定口径：分母为获同意后真实 model_view_start；同 viewId 最多一个 success/failure 终态，超时记 failure；终态 durationMs 的有效样本算平均耗时并带 samples，无样本为 null，零成功且有样本才为0%，拒绝分析样本不补分母。
- [[E-66]]　运维指标扩展及角色权限
    - 触发：SALES、EDITOR 或未登录用户直接访问运维接口或导出地址
    - 期望：按09/10节来源矩阵直接测：ADMIN全来源、SALES受既有 scope 的业务聚合、EDITOR公开流量/产品/3D；直接请求系统敏感来源403，混合来源响应在查询前裁剪且不含被隐藏计数。
