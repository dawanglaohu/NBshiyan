# M3-T6　接通唯一登录页和明确方式字段

- 所属模块：[[M3]]　后台访问与账号：负责统一后台登录页和后台公共外壳、个人设置、设备会话、验证器绑定与登录方式切换、会话撤销及独立受限恢复；消费 M1 的视觉 token。
- 前置依赖：[[M3-T2]]、[[M1-T2]]、[[M1-T1]]、[[M1-T8]]、[[M1-T7]]、[[M6-T4]]
- 完成后解锁：[[M3-T10]]、[[M3-T11]]、[[M7-T2]]

## 输入 / 产出

- **输入**：M3-T2 Credentials及M1 token/client基础；07登录路由、11/12登录单卡。 M6-T4已提供真实/admin/stats，T7外壳/账户活动客户端已在该前置链交付。
- **产出**：/admin-login、Auth.js pages.signIn、LoginForm及页脚入口；只实现日常登录UI。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 入口：公开页脚Administrator sign-in（footer-admin-login）→/admin-login
数据源Auth.js GET/POST /api/auth/[...nextauth]
点login-submit实际提交CSRF/Credentials并验证cookie与GET account，totp只email/totp，password方式界面密码控件提交Auth.js的password字段，界面解释账号不是第二因素（[[E-09]]）。2) 未勾选/缺rememberDevice与字面false的真实表单请求使设备remembered=false，勾选true才true，非法值不签session（[[E-95]]）。3) 对未知mode、未开启totp账号、非空recoveryCode与不存在账号分别直送Credentials，断言同一通用失败、无新增设备和无账号差异
合法password/totp各自真实成功
无日常恢复码字段，非站内/无当前角色权限回跳不采用（[[E-96]]）。 按11节唯一minimalist-flat，在实际服务1920×1080、1440×900、390×844记录GIF与computed style：2px黑边、0圆角、无阴影、强调色#b45700
后台逐页以work/form/card、density7/gutter16/gap16/pad16运行D1–D6和overflow探针。label与键盘焦点可达，触屏控件点击框至少44px。
4) 空/default /admin成功回跳实际到已存在的/admin/stats，断言GET /api/admin/stats及可见核心看板
404或仅redirect URL不算成功。

## 必须处理的边界

- [[E-09]]　C-03 验证器绑定与无密码默认开关
    - 触发：界面沿用用户称呼“2FA”
    - 期望：说明当前无密码模式是“账号 + 验证器码”；账号标识不是独立因素，不宣称其具备两个独立因素的安全等级。
- [[E-95]]　登录记住设备字段
    - 触发：Auth.js表单rememberDevice为字面false、缺值或布尔false
    - 期望：明确解析为false并使用普通2小时策略；不能用Boolean或无约束coerce变成记住设备；其他非法值拒绝
- [[E-96]]　登录方式枚举与账号隐私
    - 触发：mode未知、totp模式未获账号本人启用或普通Credentials携非空recoveryCode
    - 期望：列明每种非法 mode、未由本人开启的totp、普通Credentials带非空recoveryCode都沿同一通用Auth.js失败结果，不签后台会话且响应不区分账号存在；合法password/totp只校验相应方式，并按既定限流/错误协议测试，保留有效用户登录。
