# M2-T3　接通模型键盘触屏与复位控件

- 所属模块：[[M2]]　产品与 3D：负责产品列表、卡片和详情中的产品表达、直接模型操控、输入冲突处理、触屏与键盘查看、图片回退及带产品上下文的询盘入口。
- 前置依赖：[[M2-T2]]
- 完成后解锁：[[M2-T6]]

## 输入 / 产出

- **输入**：model-pointer、每产品初始相机/缩放边界与现有大卡
- **产出**：model-accessibility；键盘/单指/双指/复位与44px控件

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) Tab逐个到达命名控件且焦点可见，方向/缩放/复位与鼠标功能相同
Escape退出并回来源控件，不锁Tab、不自动跳产品链接（[[E-101]]）。2) 分别测试模型单指拖动、双指min/max内缩放、文字区页面滚动，所有操作只在模型区接管且不提交询盘
逐个测点击目标≥44 CSS px（[[E-102]]）。3) 任意旋转/缩放后复位等于该产品初始相机/边界
1440/1920及窄屏完整模型可见、名称/关键控件符合11节字号且规格/询盘仍可见，不通过删内容消除裁切（[[E-104]]）。

## 必须处理的边界

- [[E-101]]　键盘模型查看
    - 触发：键盘聚焦模型控制区后使用方向/缩放/复位控件
    - 期望：所有控件有可辨名称、可见焦点和相同功能；Escape离开操作返回来源控件，不锁住Tab或自动跳产品链接
- [[E-102]]　触屏手势
    - 触发：手指在模型视口拖动/双指缩放或在卡片文字区域滑动
    - 期望：以单指模型拖动、双指缩放、文字区滑动分别验证：仅模型操作区接管拖动，缩放不能越该产品已定义 min/max，文字/页面滚动可用；测量每个控件点击目标≥44 CSS px，任一手势不触发询盘提交。
- [[E-104]]　产品复位与显示
    - 触发：任意旋转/缩放后点复位，或PC 1440/1920和窄屏查看
    - 期望：以产品已有初始相机/缩放边界作基准，任意操控后复位需回到该值；在1440/1920及窄屏检查完整模型可见、名称及关键操作可辨；移除底部重复介绍后规格与询盘入口仍可见可用，不靠删内容消除裁切。

## 实施沉淀

<!-- notes:begin -->
**两条通道，不合并。** 缩放沿用 M2-T2 已验收的 `zoomId`/`zoomDelta`（`requestZoom` + `dollyIn/dollyOut`），方向键与复位走新的 `commandId`/`CameraAction`。合并成一条曾让「按钮缩放」与「键盘旋转」互相覆盖 id：同一次重渲染里只剩最后一个动作生效。分开后两条 id 各自递增，互不吞并；`tests/m2-t2-model-pointer.test.ts` 锁定的 `requestZoom` 字面量也得以原样保留。

**E-101 的接管条件是真实焦点归属，不是「有卡片可见」。** `onKey` 只看 `pointerRef.current.focusedSlug`——焦点移出控制区时 `blur-region` 已把它清空，因此 Tab 天然能离开，不需要额外的焦点陷阱。按键表里 `Tab`、`Escape` 与任何带 Ctrl/Cmd/Alt 的组合都返回 `null`：`Ctrl+-`、`Ctrl+0` 属于浏览器页缩放，抢走它们会破坏既有浏览器行为。

**复位基准必须在取景时记录一次，且此后不可改写。** 开合盖会把镜头拉远 10%（`openDollyFactor`），若把「当前相机」当基准，点复位会回到开盖视角而不是产品初值。故 `initialRef` 只在 `!initialRef.current` 时写入，位置/看向点/距离三项一起存；复位用 `target.set` + `position.set` 恢复，不经过缓动，保证逐项相等而非「接近」。

**44px 目标没有写进 `globals.css`。** 契约有效路径只有 `src/components/three/`、`src/lib/three/`、`e2e/model-accessibility.spec.ts`，改全局样式属于越界；而 `globals.css:510` 只在 `pointer:coarse` 或 ≤1023px 时把工具条按钮加高到 44px，桌面键盘/鼠标用户拿到的是 36px，与 11 节「触屏目标 ≥44×44」不符。改为组件内联 `TOUCH_TARGET_STYLE`，随组件走且对所有指针类型一致。

**组件级 CSS 文件会让 Node 原生单测直接崩。** 起初新建 `model-accessibility.css` 并在组件里 `import`，`tests/product-card-links.test.ts` 等以 `node --import tsx` 直接 import 组件的用例报 `SyntaxError: Unexpected token '.'`——tsx 不解析 CSS。故删除该文件，样式改为内联，未在仓库留下不可用的 `.css`。

**踩坑：漏传 props 会让缩放静默失效，而源码字面量断言仍然全绿。** 改接新通道时两处 `<ModelOrbit>` 一度只传 `commandId`/`command`，没传 `zoomId`/`zoomDelta`；单测只核对 `dollyIn/dollyOut` 的字面量，全部通过，但真实页面上缩放按钮与键盘加减号都没反应。冒烟实测发现：距离恒为 `0.9475`。修复后补了 `tests/m2-t3-model-accessibility.test.ts` 的调用点守卫，逐个 `<ModelOrbit>` 断言两条通道都传齐。
