# M2-T3　接通模型键盘触屏与复位控件

- 所属模块：[[M2]]　产品与 3D：负责产品列表、卡片和详情中的产品表达、直接模型操控、输入冲突处理、触屏与键盘查看、图片回退及带产品上下文的询盘入口。
- 前置依赖：[[M2-T2]]
- 完成后解锁：[[M2-T6]]

## 输入 / 产出

- **输入**：model-pointer、每产品初始相机/缩放边界与现有大卡
- **产出**：model-accessibility；键盘/单指/双指/复位与44px控件

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) Tab逐个到达命名控件且焦点可见，方向/缩放/复位与鼠标功能相同
Escape退出并回来源控件，不锁Tab、不自动跳产品链接（[[E-101]]）。2) 分别测试模型单指拖动、双指min/max内缩放、文字区页面滚动，所有操作只在模型区接管且不提交询盘
逐个测点击目标≥44 CSS px（[[E-102]]）。3) 任意旋转/缩放后复位等于该产品初始相机/边界
1440/1920及窄屏完整模型可见、名称/关键控件符合11节字号且规格/询盘仍可见，不通过删内容消除裁切（[[E-104]]）。

## 必须处理的边界

- [[E-101]]　键盘模型查看
    - 触发：键盘聚焦模型控制区后使用方向/缩放/复位控件
    - 期望：所有控件有可辨名称、可见焦点和相同功能；Escape离开操作返回来源控件，不锁住Tab或自动跳产品链接
- [[E-102]]　触屏手势
    - 触发：手指在模型视口拖动/双指缩放或在卡片文字区域滑动
    - 期望：以单指模型拖动、双指缩放、文字区滑动分别验证：仅模型操作区接管拖动，缩放不能越该产品已定义 min/max，文字/页面滚动可用；测量每个控件点击目标≥44 CSS px，任一手势不触发询盘提交。
- [[E-104]]　产品复位与显示
    - 触发：任意旋转/缩放后点复位，或PC 1440/1920和窄屏查看
    - 期望：以产品已有初始相机/缩放边界作基准，任意操控后复位需回到该值；在1440/1920及窄屏检查完整模型可见、名称及关键操作可辨；移除底部重复介绍后规格与询盘入口仍可见可用，不靠删内容消除裁切。
