# M3-T8　显示本人设备并退出指定设备

- 所属模块：[[M3]]　后台访问与账号：负责统一后台登录页和后台公共外壳、个人设置、设备会话、验证器绑定与登录方式切换、会话撤销及独立受限恢复，并负责既有后台页面的共享视觉迁移/回归；不改其询盘/邮件/规格/模型业务，消费 M1 的唯一视觉 token。
- 前置依赖：[[M3-T12]]、[[M3-T17]]
- 完成后解锁：[[M3-T13]]、[[M7-T2]]

## 输入 / 产出

- **输入**：M3-T12共享ReauthDialog、M3-T17设备API。
- **产出**：/admin/account/devices、DevicesContainer/DeviceRow、本人游标页与单设备撤销。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 入口：个人页Signed-in devices（account-devices-link）→/admin/account/devices
数据源GET /api/admin/account/devices
1/2/多页仅本人行，current/expiry/revoked由DTO，分页同ID恰一次
GET不续activity（[[E-70]]）。2) 点device-revoke-{id}复用ReauthDialog→POST reauth(DEVICE_REVOKE,target=id)→POST /api/admin/account/devices/[id]/revoke
断言目标设备下一GET account401、其他未撤设备仍有效，撤当前设备清屏回login
跨target和已用grant无变更（[[E-73]]）。 按11节唯一minimalist-flat，在实际服务1920×1080、1440×900、390×844记录GIF与computed style：2px黑边、0圆角、无阴影、强调色#b45700
后台逐页以work/form/card、density7/gutter16/gap16/pad16运行D1–D6和overflow探针。label与键盘焦点可达，触屏控件点击框至少44px。

## 必须处理的边界

- [[E-70]]　设备会话与Auth.js期限接合
    - 触发：cookie/JWT 仍有效，但设备已撤销、账号禁用、凭证版本变化或服务端校验不可用
    - 期望：受保护请求不得仅凭 cookie 放行；在请求范围内去重查询不能演变成跨请求忽略撤销的缓存。
- [[E-73]]　敏感设置的新鲜本人验证
    - 触发：两次请求并发使用同一 ActionGrant，或把改密码授权用于关闭验证器
    - 期望：在敏感变更事务内按动作、设备、账号及凭证版本校验并一次性消费授权，只有一个匹配请求成功，目的不符请求拒绝且不能执行变更。
