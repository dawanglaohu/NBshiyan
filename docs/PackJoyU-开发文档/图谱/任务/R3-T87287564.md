## 实施沉淀

<!-- notes:begin -->
文件身份只替换分隔符。`docs/a.md` 与 `docs\a.md` 是同一条；`docs/a.md` 与绝对路径、大小写不同的路径、带 `.` / `..` 或末尾斜杠的路径都不是。允许名单的 `file` 必须写成扫描报告的那条字符串。空 `file` 仍表示该词在所有文件放行。

读目录用 `path.join` 得到的原路径。返回和排除才用斜杠身份。比较前不要 `realpath`，否则两条不同字符串指向同一 inode 时会共用一条允许记录。

校对稿和 design HTML 的排除作用在斜杠身份上。命令行显式传入的文件不经目录扫描，仍然检查。直接执行条件仍是 `import.meta.url` 与 `` `file://${argv[1]}` `` 的字符串比较。在 Windows 上该比较不成立，进程以 0 退出且不读文件。本任务的扫描证据是 `defaultFiles` 和测试里的目录遍历，不改这个比较。

缺的根目录只贡献空列表。词表里的 е 必须留下命中。不能靠删扫描根，或把期望改成空列表，让 Windows 通过。

`MOCK_FILE` 只认 `/`。`src/lib/` 之外的 `*-mock.ts` 必须仍出现在发现结果里，并因为不在 `src/lib/` 下而失败。静态 import 检查继续覆盖非 mock 源文件。
