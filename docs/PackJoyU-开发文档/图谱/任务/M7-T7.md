# M7-T7　终验运维来源与通知重启消费

- 所属模块：[[M7]]　集成验收与交付：负责访客跨模块完整路径、后台权限与恢复路径、统计和可靠性完整链路的真实集成验收及交付证据收口；核对本轮复用的恢复来源，不重做 S1 已完成的取回和来源审计，也不自动合并恢复草稿。
- 前置依赖：[[M6-T7]]、[[M4-T4]]、[[M5-T1]]、[[M5-T8]]
- 完成后解锁：[[M7-T8]]

## 输入 / 产出

- **输入**：stats-reliability/ops-sources、真实cron与独立聊天SMTP适配器
- **产出**：operations-acceptance；来源异常及真实通知调度报告

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 隔离SMTP接收真实聊天通知，核attempt/sent/failed/unknown与HTTP计数的明确覆盖
停止单辅助来源后stats保留原成功时间/旧值或未接入且核心继续可读，未验证备份不标可恢复（[[E-64]]、[[E-65]]、[[E-67]]）。2) 直接以未登录/EDITOR会话调用人工通知相关受保护入口被拒，cron仅Bearer
chat-notifications独立受限适配器不扩旧mail UI，实际cron每分钟登记，保存消息后重启并等待计划消费持久出箱
不能只手动调HTTP或写空注册，保存received不受通知失败回滚（[[E-94]]）。

## 必须处理的边界

- [[E-64]]　运维指标扩展及角色权限
    - 触发：接口或邮件已接真实结果来源
    - 期望：展示脱敏且口径明确的错误率与通知失败计数，邮件失败按真实发送尝试记录，不把排队、已调用发送函数或普通询盘收件等同于成功投递。
- [[E-65]]　运维指标扩展及角色权限
    - 触发：存储健康或备份没有可验证来源
    - 期望：仅显示未接入及来源状态；接通后显示真实检查/完成时间，不以普通文件上传、页面查询成功或计划时间假装备份成功，也不暗中新增备份平台或付费服务。
- [[E-67]]　运维指标扩展及角色权限
    - 触发：任一附加来源中断或无数据
    - 期望：该卡独立显示错误、旧值、未知或未接入；其他真实指标仍可查询，避免单个辅助来源拖垮整张看板。
- [[E-94]]　聊天通知持久队列
    - 触发：出箱/通知接口被无聊天权限角色调用，或 SMTP 适配器仅能发送既有询盘格式
    - 期望：分别验无权限调用拒绝、chat-notifications 使用独立受限适配器且不扩展旧 mail UI；deploy/cron.nbshiyan 确有每分钟注册，重启后实际消费已提交出箱，不能只有手工调用或未来空注册。M4随交付注册，M7仅最终验收。
