# M6-T1　定义统计查询范围与核心来源DTO

- 所属模块：[[M6]]　业务与运维看板：负责按角色查询并解释统计结果，读取询盘、聊天、接口错误、邮件、存储和备份的真实来源，区分数据时间、零值、无数据、未接入、失败和旧值。
- 前置依赖：[[M5-T3]]、[[M2-T4]]、[[M2-T7]]
- 完成后解锁：[[M6-T6]]

## 输入 / 产出

- **输入**：真实AnalyticsDaily及JobState结构、09来源矩阵、10 StatsDTO
- **产出**：stats-query-rules；核心来源DTO与只读聚合查询规则，接线由M6-T6交付

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 专用PG测试按同一timezoneRevision与左闭右开日区间读取AnalyticsDaily
成功且确有0输出zero并有成功查询时间与授权覆盖，未覆盖区间输出no_data/null，来源未配置或任务未接通输出not_connected，不从产品UV相加算全站UV（[[E-49]]、[[E-50]]）。2) 对真实modelStarts/successes/failures/duration samples计算：无样本null、有样本零成功为0%、终态样本平均值正确且分母仅授权start
不同查看者时区读到相同站点日和值（[[E-55]]、[[E-63]]）。

## 必须处理的边界

- [[E-49]]　C-06 看板数据时间与异常状态
    - 触发：数据源已接通、查询成功且所选日确有 0 条符合口径的事件
    - 期望：展示数值 0、查询成功时间及授权统计范围，不伪报查询失败或尚未接入。
- [[E-50]]　C-06 看板数据时间与异常状态
    - 触发：首次启用、数据源未接通或尚无可查询数据
    - 期望：分别显示尚无数据或未接入及具体来源，不以 0 冒充真实统计，不把“今日无事件”单独判作采集故障。
- [[E-55]]　今日统计的站点时区与历史重算
    - 触发：浏览器或操作系统时区不同的两名运营查看同一日
    - 期望：使用同一站点时区与同一日区间，数值口径不因查看者位置改变，图表及导出标出站点时区。
- [[E-63]]　运维指标扩展及角色权限
    - 触发：3D 加载有成功、失败、超时或没有样本
    - 期望：引用09节既定口径：分母为获同意后真实 model_view_start；同 viewId 最多一个 success/failure 终态，超时记 failure；终态 durationMs 的有效样本算平均耗时并带 samples，无样本为 null，零成功且有样本才为0%，拒绝分析样本不补分母。
