- `AnalyticsDaily` 按站点日、时区 revision 和站点／产品维度保存无身份计数；只保存浏览器去重后的数量，不保存 browserHash、eventId、viewId、navigationId、IP 或 UA。耗时记录 BigInt 总和与有效样本数，均值用总和除样本数；产品 pageViews 为 null，成功率以 start 为分母。
- 站点日读取使用同一快照与 Q1–Q5，统一过滤冒烟路径；按 `(browserHash, viewId)` 配对 start 和终态，并按 `occurredAt <= notAfter` 分为计入与 defer。站点和各产品独立去重，产品 UV 不可相加成站点 UV。
- 事件写入与 UTC 日 marker bump 共用事务；终态额外标脏配对 start 的 UTC 日。日状态记录 markerVersions、defer 和 gap；缺键按 0 比较，无 site 行为 no_data，缺状态、gap、defer 或 live 版本前进为 partial。这里只提供 M6 可复用的分类原语。
