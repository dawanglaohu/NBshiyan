# M4-T9　集成聊天轮询、断网重试与失权停止

- 所属模块：[[M4]]　第一方人工咨询：负责访客必要会话、人工消息与离线留言、ADMIN/SALES 收件箱和回复、未读、失败草稿与幂等重试，并保存真实收件和通知结果。
- 前置依赖：[[M4-T5]]、[[M4-T11]]
- 完成后解锁：[[M2-T8]]、[[M4-T6]]、[[M4-T13]]

## 输入 / 产出

- **输入**：M4-T5实际访客UI、全部消息API，09/10 seq与1/2/4/8/16/30s协议。
- **产出**：chat-poller与ChatContainer真实装配；3s同步、原key消息重试、失效/断网分支。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 入口：/contact联系人工→chat窗口
数据源GET /api/chat/conversations/[id]、POST messages/read
可见正常3s、hidden零轮询、恢复即补页，单在途，慢网失败退避1/2/4/8/16/30s
乱序/跨页插入每ID恰一次、seq不退、read仅实际可见最大完整seq（[[E-76]]、[[E-77]]）。2) 实际服务成功存消息后截断响应，UI待确认保留原UUID/body/email，点chat-retry重发原payload返回原receipt
运营实际GET只有一消息/出箱一条
未落库断网草稿仅标签页内存、刷新不承诺恢复（[[E-18]]、[[E-37]]、[[E-38]]）。3) cookie过期/撤销及运营角色撤权后下一poll和send均服务器拒绝且无正文/无写
改threadId/seq/email不能越权，UI停止定时器和旧发送、保留当前草稿并显示明确新咨询，不自动换UUID或跨线程重发（[[E-78]]、[[E-85]]）。 按11节唯一minimalist-flat，在实际服务1920×1080、1440×900、390×844记录GIF与computed style：2px黑边、0圆角、无阴影、强调色#b45700
后台逐页以work/form/card、density7/gutter16/gap16/pad16运行D1–D6和overflow探针。label与键盘焦点可达，触屏控件点击框至少44px。

## 必须处理的边界

- [[E-18]]　在线聊天实现路线
    - 触发：同一消息因重试重复提交
    - 期望：按客户端消息标识去重，收件箱只出现一条，不重复触发通知。
- [[E-37]]　C-02 离线留言与发送失败恢复
    - 触发：提交超时或响应丢失、实际保存状态未知
    - 期望：显示待确认或可重试，以原客户端消息标识重试并返回原收件结果，收件箱与通知不产生重复项。
- [[E-38]]　C-02 离线留言与发送失败恢复
    - 触发：网络中断且尚未保存
    - 期望：消息与可选邮箱只留在当前标签页内存，可重试并提供现有联系邮箱入口；刷新、关闭或崩溃后不承诺恢复草稿，也不写入 localStorage 或日志。
- [[E-76]]　人工聊天同步机制
    - 触发：聊天/收件箱可见且请求成功
    - 期望：以 3 秒为正常间隔；标签页隐藏时暂停，恢复可见立即从已确认 seq 补齐；慢网或连续失败采用有界退避，间隔最多 30 秒，任一轮不能叠加无限在途请求。
- [[E-77]]　人工聊天同步机制
    - 触发：多个标签页、重试、响应乱序或跨分页期间又插入新消息
    - 期望：以服务端稳定 seq 和消息标识合并去重，游标只推进到已完整接收的范围；后返回的旧响应不能倒退游标、覆盖新回复或把漏页消息跳过。
- [[E-78]]　人工聊天同步机制
    - 触发：访客会话到期/撤销，或运营角色从 ADMIN/SALES 变为无聊天权限
    - 期望：下一次轮询和发送均做服务端鉴权并停止返回会话内容；修改 threadId、seq 或邮箱不能读取其他咨询。
- [[E-85]]　聊天凭据及数据保留期限
    - 触发：cookie 闲置达到 7 天、签发达到 30 天绝对上限或被撤销
    - 期望：服务端拒绝该凭据访问旧会话，浏览器可建立新咨询；仅填写相同邮箱不能找回旧会话，cookie 与其前端副本均不存 PII。
