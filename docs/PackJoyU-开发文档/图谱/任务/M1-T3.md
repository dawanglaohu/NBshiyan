# M1-T3　制作JPG换标及视频海报发布副本

- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T1]]
- 完成后解锁：[[M1-T6]]、[[M1-T9]]

## 输入 / 产出

- **输入**：桌面原JPG/视频、现用PackJoyU字标、来源与原件哈希登记
- **产出**：brand-static-media；用户已确认的工业风静态PNG、视频语义海报及压缩视频副本、哈希/对照清单 brand-logo-master；从当前SiteHeader字标/icon.svg导出的现用品牌基准文件public/brand/packjoyu-logo-master.svg及来源/导出哈希。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 原JPG/GIF/视频哈希不变，选定输出均可解码
静态发布图采用用户已确认的工业风PNG，替代早期局部换标JPG，核对飞艇和工厂两处PackJoyU标识及旧标清除结果，不要求重做已弃用局部换标版本
视频海报取自实际选定的换标成片，登记精确帧时刻、成片与海报哈希。原片公司名称、logo、片头尾和水印的时间点观察清单保留，发布身份审查逐项核实际选定成片
已授权替换且复核无残留的原产品商标，不单凭原片商标或未知客户关系阻断该成片。真实设备商标只记录，不当作企业署名或擅自抹除。成片仍有不符的企业署名、片头尾、水印或来源无法确认时禁止发布
不修改原视频，不擅自删镜头、重排或改变音轨。2) 即使候选设计与线上字标不同仍使用当前PackJoyU字标，记录所用标识文件哈希
不等待用户回看候选图，不把候选当已批准新logo（[[E-28]]）。3) 按用户授权的实际制作渠道保留输入、工具调用或软件操作、输出文件和成品核对记录
素材已通过其他授权渠道制作时，不因未使用GPT Dot判为未执行。实际使用GPT Dot时保留对应调用证据
尚未实际制作的项目逐项登记尚未执行及具体实施任务，不伪称调用成功或成品完成（[[E-29]]）。
4) 先核项目当前SiteHeader字标、样式/字体和icon.svg来源，导出可供软件导入的现用完整字标master，记录源文件与导出文件SHA256，逐项核字形、比例、颜色与当前标识一致
不重新设计候选标、不修改源字标或图标。SVG不得含script、外部引用或私有元数据
后继T6/T9只引用此已核master。
5) docs/brand-media/static/brand-static-media.json逐文件登记path/sha256/width/height，与实际解码/哈希逐值核对，并明确选定发布文件与历史待核副本
logoMaster登记sourceFiles的path/sha256、导出path/sha256/viewBox及所用字体/样式来源，重新读取均与清单相等。docs/brand-media/static/video-identity.json分别保留原片观察和选定成片复核
成片复核绑定原片及输出path/sha256，对企业署名、片头尾、水印及替换区域登记fromMs/toMs、实际文字或标识、抽帧sha256、OWN_VERIFIED/THIRD_PARTY/UNKNOWN与可打开依据，时间须在片长内
海报绑定该成片和帧时刻。直接用户来源声明可作依据并注明陈述范围，不推导未陈述的工厂产权、客户合作、认证或产能。成片来源或企业署名仍UNKNOWN时releaseAllowed=false且T4不能称发布通过
设备商标单独标role=equipment，不据此换企业身份。缺任何必要发布副本、成片核验或真实制作记录时T3仍未完成，不以清单或未执行说明替代成品。

## 实施沉淀

<!-- notes:begin -->
- 当前字标的 Pack/U 继承 `--pj-fg`，Joy 使用既有 `--accent-text`；不能用旧 `--ink` 或新 UI 强调色替换品牌色。icon 是来源核对对象，不拼入当前纯文字页头。
- Manrope 800 的 Pa/oy 有 kerning；逐字无字距转曲会改变比例。已提交 TTF 与实际 Next 加载的 Latin WOFF2 的轮廓、advance、kerning 严格相等；浏览器三个 inline run 的 1/64px 量化差单独记录，不拉伸 SVG 迁就像素宽度。
- 原片有设备商标和 Holiland/好利来产品标识；设备角色不推导企业身份，收到视频不证明 PackJoyU 客户或工厂关系。模糊印字、企业归属或关系 UNKNOWN 时，视频和海报候选均不入发布集合。
- 生成工具能消除旧标，但可能重绘非换标区及字形；可读文字不证明轮廓等于精确 master。JPG 保真待核和身份未明的视频/海报存入 heldFiles，不进入 releaseFiles；真实副本存在也不能直接给 T4 发布通过结论。
- 新风格图以原图为主题参考，用户明确允许改构图和材质；不得沿用局部换标版本的像素保真要求打回新风格，也不得据此把生成插画当作真实工厂或客户证明。
- 派生视频产品字标按授权改为PackJoyU；原片身份清单用于记录未经编辑的输入，发布仍取决于可核来源依据。
- 纸面换标不能把旧字清除区域当作物理矩形；原片印刷行与纸角确定文字投影，斜坡纸面和下方纸面分别校准。v3视频及海报保存透视修订，v2副本与复现提交保留。
- 视频来源另有用户直接说明：员工在工厂拍摄，PackJoyU标识由助手后加；陈述范围见source-attestation.json，不推导工厂产权或原产品客户关系。发布核验须绑定实际选定成片，原片产品商标观察作为历史保留。
<!-- notes:end -->
