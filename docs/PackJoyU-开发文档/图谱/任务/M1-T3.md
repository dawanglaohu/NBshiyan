# M1-T3　制作JPG换标及视频海报发布副本

- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T1]]
- 完成后解锁：[[M1-T6]]、[[M1-T9]]

## 输入 / 产出

- **输入**：桌面原JPG/视频、现用PackJoyU字标、来源与原件哈希登记
- **产出**：brand-static-media；换标JPG、视频语义海报及压缩视频副本、哈希/对照清单 brand-logo-master；从当前SiteHeader字标/icon.svg导出的现用品牌基准文件public/brand/packjoyu-logo-master.svg及来源/导出哈希。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 原JPG/视频哈希不变，输出文件均可解码
将JPG飞艇与工厂墙面的旧标逐处列入清单并以现用PackJoyU字标完整替换，清单逐处核无旧标，视频海报取自其自身画面且带可核帧时刻
对全片所有公司名称、logo、片头/片尾及水印列时间点清单，片头/片尾/水印等企业署名与己方身份不符或依据缺失时该发布副本不入成品并报告
真实场景中的设备商标只记录，不自动当企业署名或擅自抹除，不修改原视频、不擅自重剪。2) 即使候选设计与线上字标不同仍使用当前PackJoyU字标，记录所用标识文件哈希
不等待用户回看候选图，不把候选当已批准新logo（[[E-28]]）。3) GPT Dot可达且实际制作时保留调用、软件操作、输出文件和成品核对记录
不可达则逐项写尚未执行/实施任务且该项不称完成，不伪称调用成功（[[E-29]]）。
4) 先核项目当前SiteHeader字标、样式/字体和icon.svg来源，导出可供软件导入的现用完整字标master，记录源文件与导出文件SHA256，逐项核字形、比例、颜色与当前标识一致
不重新设计候选标、不修改源字标或图标。SVG不得含script、外部引用或私有元数据
后继T6/T9只引用此已核master。
5) docs/brand-media/static/brand-static-media.json逐文件登记path/sha256/width/height并与实际解码/哈希逐值核对
logoMaster登记sourceFiles的path/sha256、导出path/sha256/viewBox及所用字体/样式来源，重新读取均与清单相等。docs/brand-media/static/video-identity.json对企业署名/片头尾/水印每项列fromMs/toMs、画面精确文字或标识、抽帧sha256及OWN_VERIFIED/THIRD_PARTY/UNKNOWN与依据路径，时间须在0至原片时长内
抽帧和依据可打开。第三方企业署名或UNKNOWN时releaseAllowed=false且T4不能称发布通过
普通设备商标单独标role=equipment，不据此换企业身份。缺任何发布副本或真实制作记录时T3仍未完成，不以清单或未执行说明替代成品。
