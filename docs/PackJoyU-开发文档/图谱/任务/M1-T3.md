# M1-T3　制作JPG换标及视频海报发布副本

- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T1]]
- 完成后解锁：[[M1-T6]]、[[M1-T9]]

## 输入 / 产出

- **输入**：桌面原JPG/视频、现用PackJoyU字标、来源与原件哈希登记
- **产出**：brand-static-media；用户已确认的工业风静态PNG、视频语义海报及压缩视频副本、哈希/对照清单 brand-logo-master；从当前SiteHeader字标/icon.svg导出的现用品牌基准文件public/brand/packjoyu-logo-master.svg及来源/导出哈希。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 原JPG/GIF/视频哈希不变，选定输出均可解码。静态采用用户已确认工业风PNG，核飞艇和工厂两处PackJoyU及旧标清除，不重做已弃用局部换标JPG。海报取实际选定换标成片，登记精确帧时刻及成片/海报SHA。保留原片公司名称、Logo、片头尾、水印时间点观察，逐项核实际成片
已授权替换且无残留的原产品商标及未知客户关系不单独阻断。设备商标保留、单列equipment，不作企业署名。成片仍有不符企业署名/片头尾/水印或来源未明则禁发
不改原片、删镜头、重排或改变音轨。2) 候选与线上字标不同时仍用当前PackJoyU，不等待用户回看、不当作批准新标（[[E-28]]）。3) 按用户授权的实际渠道保留输入、真实工具调用/软件操作、输出与核对记录
其他授权渠道已制作，不因未用Dot判未执行。使用Dot时留对应调用证据
未制作项逐项写尚未执行及具体任务，不伪称成功/完成（[[E-29]]）。4) 先核当前SiteHeader字标、样式/字体及icon.svg来源，导出可供软件导入的现用完整master，登记源/导出SHA
逐项核字形、比例、颜色与当前标识一致，不重设计或修改源标/icon。SVG不得含script、外部引用、私有元数据
T6/T9只引用此master。5) brand-static-media.json逐文件登记path/sha256/width/height，实际哈希/解码逐值匹配，分开选定发布与历史待核副本。logoMaster含sourceFiles路径/SHA、导出路径/SHA/viewBox及字体/样式来源，重读相等。video-identity.json保留原片观察并另核选定成片
成片绑定原片和输出path/SHA，对企业署名、片头尾、水印、替换区逐项登记fromMs/toMs、实际文字/标识、抽帧SHA、OWN_VERIFIED/THIRD_PARTY/UNKNOWN及可打开依据，时刻在片长内
海报绑定成片及帧时刻。直接用户来源说明可作依据并限定范围，不推导未陈述产权、客户、认证、产能。来源或最终署名UNKNOWN则releaseAllowed=false，T4不得称发布通过
设备商标不推导企业身份。缺必要发布副本、成片核验或真实制作记录则T3未完成，不能以清单或未执行说明代替成品。
