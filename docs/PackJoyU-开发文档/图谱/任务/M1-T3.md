- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T1]]
- 完成后解锁：[[M1-T6]]

## 输入 / 产出

- **输入**：桌面原JPG/视频、现用PackJoyU字标、来源与原件哈希登记
- **产出**：brand-static-media；换标JPG、视频语义海报及压缩视频副本、哈希/对照清单

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 原JPG/视频哈希不变，输出文件均可解码
将JPG飞艇与工厂墙面的旧标逐处列入清单并以现用PackJoyU字标完整替换，清单逐处核无旧标，视频海报取自其自身画面且带可核帧时刻。2) 即使候选设计与线上字标不同仍使用当前PackJoyU字标，记录所用标识文件哈希
不等待用户回看候选图，不把候选当已批准新logo（[[E-28]]）。3) GPT Dot可达且实际制作时保留调用、软件操作、输出文件和成品核对记录
不可达则逐项写尚未执行/实施任务且该项不称完成，不伪称调用成功（[[E-29]]）。
