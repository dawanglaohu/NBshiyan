## 实施沉淀

<!-- notes:begin -->
选定素材是一幅英文公司介绍图，源工程含八个图层、65 个独立文字对象和 79 条路径。概念性包装插画与十二个品类名称不代表真实厂房、设备或产品照片。参考 PDF 第 2 页只提供公司概览和配套视觉的组织主题；不移植其地图、客户数、产能、认证或企业历史。自有工厂、整合供应链、多品类定制、设计打样与质量把控的定性表述由用户直接确认，依据保存在 `docs/brand-content/source/company-facts-attestation.json`。

正式字标使用 master 的八条原始路径和颜色；导入组为 `logo-master-import`，保持统一缩放。图稿白底位于字标之下。源件与 PNG 的 SHA-256 均针对文件原始字节，任何换行、填色或几何变化都必须重新核验；`.gitattributes` 保护已登记文件免于 Git 换行转换。英文和俄文 alt 描述同一英文画面，不把英文成品冒称为俄文图稿。

Dot 的实际制作环境是云端 Linux、Inkscape 1.4。记录中的标识属于父会话，不是 Inkscape 调用号，也不表示 Windows 本机任务服务已经恢复。八张截图包含对象图层、实际 PNG/PDF 导出设置、从磁盘重开的工程、标题追加临时 X 后撤销及独立杯套路径节点。临时编辑撤销后不保存，最终源件哈希保持不变。`receipt.json` 将记录和截图逐件绑定到最终源工程与 Web 图。

完整素材验收运行 `python -B docs/brand-content/source/verify_company_visuals.py --verify-originals`，必须读取并核对清单配置的原始 PDF/JPG/GIF/视频；原件缺失或变化即失败。不带该选项只核交付文件和记录，明确输出 `desktop-originals=not-requested`，不能据此宣称原件验收完成。自动检查只证明文件和记录一致，软件操作本身由真实截图人工核对。回归命令为 `python -B -m unittest discover -s docs/brand-content/source -p test_company_visuals.py -v`。

两幅早期 SVG/PNG 和 Inkscape 记录作为历史底稿保留，旧清单位于 `source/history/company-visuals-before-dot-v3.json`，不属于本次选定素材。只有公开 PNG 进入 `public/brand/company/`；源工程与工具记录留在 `docs/`，由 `.dockerignore` 排除。素材完整状态不代表页面完成，首页/about 的消费、主体完整性与浏览器证据由 [[M1-T5]] 验收。
