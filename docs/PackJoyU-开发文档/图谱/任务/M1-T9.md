- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T1]]、[[M1-T3]]
- 完成后解锁：[[M1-T5]]

## 输入 / 产出

- **输入**：docs/brand-media/static/selected-media-release.json的已确认工业PNG/GIF、己方可证事实、T3现用brand-logo-master及真实制作记录；PDF/原JPG只作历史主题对照，不作新底图
- **产出**：company-visual-assets；以已确认素材复用/排版的1–2幅公司图稿、真实可编辑工程、Web图/enru alt与来源/SHA清单

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 先核docs/brand-media/static/selected-media-release.json的选定成品
选用已确认工业素材复用/排版，不重新从参考PDF/JPG/GIF重绘已确认场景
每幅列“选定文件path/SHA/用途→己方可证事实或不含企业硬事实的示意”。旧PDF仅可选历史主题对照
原附件/master SHA不变，不复制YUHAO认证/产能/规模或无依据厂房/设备/证照，不重画25页目录（[[E-27]]、[[E-111]]）。2) 每幅仍须交docs/brand-content/source/可编辑工程及public/brand/company/发布Web图
已有源件先核，缺则补工程不重画场景。用实际软件打开，选并编辑至少一独立图形/文字对象，存图层/对象面板及可撤回编辑记录，关时不覆盖登记源件。平面PNG/GIF/截图本身不是可编辑工程。解码Web图得正整数尺寸
company-visuals.json逐件含选定输入path/SHA、source.path/SHA、web.path/SHA/width/height、非空对应en/ru alt及事实/示意依据，实测逐值相等（[[E-111]]）。3) manifest绑定现用master path/SHA，读取相等，工程记录其引用/导入对象
不改源logo、不用候选或旧标、不等待回看（[[E-28]]、[[E-111]]）。4) 复用已有真实制作记录，补齐本卡实际采用软件/工具版本、打开/编辑/导出/再核验记录并逐件绑定工程/Web路径/SHA
用Dot时核实际调用，未用不虚构或因此重做。最终重开工程、解码Web、复算所有SHA
任何必需图稿/工程/Web/核验缺失都未完成，不能以素材已确认或文字计划替代（[[E-29]]、[[E-111]]）。5) 本卡只交经核素材/清单，首页/about实际消费归M1-T5，不伪造页面完成
私有工程/工具记录不入public或运行镜像（[[E-111]]）。
