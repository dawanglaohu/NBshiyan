只有平面截图不算可编辑工程。实际解码每幅Web图并测得正整数宽高。docs/brand-content/company-visuals.json每幅都含source.path/source.sha256、web.path/web.sha256/width/height、alt.en/alt.ru、参考主题/事实依据

## 实施沉淀

<!-- notes:begin -->
两幅图都把 `public/brand/packjoyu-logo-master.svg` 的八条 path `d` 原样放进 `logo-master-import`。改几何、换填色或另画字标，都会和 master 的 SHA-256 对不上。整页白底必须留在字标图层之下。白底画在字标之上时，导出的 Web 图里没有字标。

`cell-gift-boxes` 与 `form-gift-box` 盖住画布约 (550, 350)。Inkscape 1.4.4 在 1400×900 的窗口里，窗口坐标 (500, 400) 点中的就是这块矩形。挪开它们之后，色卡编辑会落到别的对象，会话记录里的对象名就不再成立。

Inkscape 1.4.4 的命令行动作表没有撤销。撤销在窗口动作组 `doc` 的 `undo`，快捷键名是 `doc.undo`。关闭进程时不能保存。一保存，临时的蓝色填色就会写进已登记的源工程，哈希随之改变。

`company-visuals.json` 的 status 必须保持 unfinished，`dot.invocationId` 必须保持 null。没有 GPT Dot 调用号时，这组素材不能算 company-visual-assets 已完成，也不能落地。首页和 about 的消费证据归 M1-T5。源工程和会话记录留在 `docs/brand-content/source/`，不进 public。

画面只使用已发布品类的英文名称和平面轮廓。YUHAO、产能、厂房、认证和尺寸表不能写进源工程。俄文只放在 alt.ru。画面文字保持英文，避免俄文标签和英文画面不一致。
