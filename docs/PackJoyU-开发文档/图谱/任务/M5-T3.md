# M5-T3　以一致快照重算并原子替换日聚合

- 所属模块：[[M5]]　同意与统计账本：负责分析同意、匿名浏览器与事件标识、采集准入和去重、站点统计时区设置、日与产品聚合、原始与聚合保留及可重算边界，产出真实访问和 3D 统计。
- 前置依赖：[[M5-T6]]、[[M5-T1]]、[[M5-T9]]
- 完成后解锁：[[M2-T7]]、[[M5-T5]]、[[M5-T8]]、[[M6-T1]]

## 输入 / 产出

- **输入**：analytics-ingest、job-leases、analytics-settings-domain及完整原始覆盖边界
- **产出**：analytics-aggregate；AnalyticsDaily日/产品聚合服务与watermark发布

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 真Postgres同一重复事件仅计一次，聚合固定RepeatableRead快照/cutoff，新到事件留下一轮
同navigationId去重，整组目标日数据与watermark一次事务替换，进程中断保留上组（[[E-80]]、[[E-81]]）。2) 并发旧generation或旧timezoneRevision提交拒绝
只重算dayStart不早于完整原始覆盖起点的日，48h迟到重算该日，超范围保留原完整值并返回partial/unavailable及原口径，不延长原始保留、不用残片变小（[[E-82]]、[[E-83]]）。3) 聚合按站点IANA左闭右开日计算23/25小时DST及午夜单归属
变时区只用仍保留事件重算，30天外保留原标签/不可重算状态（[[E-56]]、[[E-57]]、[[E-58]]）。本服务由M5-T8接真实5分钟调度。

## 必须处理的边界

- [[E-56]]　今日统计的站点时区与历史重算
    - 触发：统计日遇到夏令时切换
    - 期望：使用 IANA 时区库计算本地午夜到次日本地午夜的 UTC 边界，允许一天为 23 或 25 小时，不固定加 24 小时或重复计算重叠时刻。
- [[E-57]]　今日统计的站点时区与历史重算
    - 触发：事件恰好位于午夜或查询横跨午夜
    - 期望：采用左闭右开区间，单次查询确定一致的站点时区、日期和边界，午夜事件仅归属一个自然日。
- [[E-58]]　今日统计的站点时区与历史重算
    - 触发：ADMIN 修改有效时区
    - 期望：保留 UTC 事件时间，标记重算状态，只按仍保留的事件重聚合；已超出 30 天原始保留期的旧聚合保留原时区标签或明确不可重算，不能静默拼成统一口径趋势。
- [[E-80]]　分析聚合与水位发布
    - 触发：同一事件重试，或一次聚合读取期间新事件到达
    - 期望：采集以唯一事件标识幂等落库；聚合固定一致的来源快照及 watermark，只发布该快照覆盖的结果，新事件留给下一轮，不在已发布计数上重复滚加。
- [[E-81]]　分析聚合与水位发布
    - 触发：两个调度实例重叠，或旧任务超时后晚于新任务提交
    - 期望：使用数据库互斥或带代次的租约及提交校验，旧任务不能覆盖新结果；一次事务替换整组目标日数据并提交 watermark，进程中断保留上次完整结果。
- [[E-82]]　分析聚合与水位发布
    - 触发：原始事件在允许迟到范围内入库
    - 期望：明示仅重算 dayStart 不早于完整原始覆盖起点的自然日；超范围保留原聚合并返回 partial/unavailable 及原口径/覆盖，不以清理后的残片替换旧完整计数。迟到范围沿09节48h，不扩原始保留期。
- [[E-83]]　分析聚合与水位发布
    - 触发：站点时区变更与作业并发
    - 期望：结果携带 timezoneRevision，旧代次不得覆盖新时区结果；仅在原始保留范围内重算，原始已清除部分不伪造恢复或静默改为零。
