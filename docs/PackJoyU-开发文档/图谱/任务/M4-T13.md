# M4-T13　在隔离授权策略下原子匿名化过期咨询

- 所属模块：[[M4]]　第一方人工咨询：负责访客必要会话、人工消息与离线留言、ADMIN/SALES 收件箱和回复、未读、失败草稿与幂等重试，并保存真实收件和通知结果。
- 前置依赖：[[M4-T7]]、[[M4-T11]]、[[M4-T4]]、[[M4-T9]]
- 完成后解锁：[[M7-T4]]

## 输入 / 产出

- **输入**：M4-T7保留策略/固定job、M4-T11真实活动写入与09事务再校验。
- **产出**：retention-service/repo匿名化分支、策略version及新活动竞争保护；仍默认dry-run且不执行生产清理。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 调用方/接线点：既有chat-retention→当前授权策略分支→事务重读lastActivityAt/retainUntil/policyVersion
只用隔离授权数据执行，扫描后新成功收发使旧候选跳过
未变的过期目标正文/email/敏感context匿名化并禁继续回复（[[E-87]]）。2) 复用M4-T9隐藏轮询/断网与M4-T4通知重试前置，仅新增retainUntil断言：重复GET刷新、隐藏页轮询、read、SMTP通知重试/回执均不改90d截止，成功保存访客消息或人工回复才推进
cookie到期不级联删内容
外键Restrict，全部咨询匿名化后才回收空session
无明确授权仍拒绝真实写且deletedCount0，既有询盘/分析/恢复/备份不变（[[E-86]]、[[E-88]]、[[E-89]]）。

## 必须处理的边界

- [[E-86]]　聊天凭据及数据保留期限
    - 触发：隐藏标签页仍有轮询，或仅刷新访问但没有成功收发咨询消息
    - 期望：这些行为不推迟消息/邮箱的 90 天保留截止；咨询活动以成功保存的访客消息或人工回复为准，不把通知重试、投递回执或读状态更新当作新咨询。
- [[E-87]]　聊天凭据及数据保留期限
    - 触发：保留清理与新的成功收发消息并发
    - 期望：清理执行事务重新检查最后咨询活动和当前策略版本；有新咨询则跳过旧截止，不能按扫描时的旧时间清除刚恢复沟通的内容。
- [[E-88]]　聊天凭据及数据保留期限
    - 触发：本轮文档被生成或实施者拿到派发任务
    - 期望：新增纯授权门禁的可测表述：生产真实清理默认关闭且 dry-run 为默认模式；不存在另行明确的保留策略授权时，启用或请求真实删除必须拒绝且删除计数为0，可返回候选计数/未启用状态。文档、任务派发、模型或代理结论均不能充当授权。只用隔离数据验证，不触碰生产/恢复/备份现有数据。
- [[E-89]]　聊天凭据及数据保留期限
    - 触发：聊天 cookie 失效但消息尚未到 90 天
    - 期望：访客历史访问立即受阻，运营仍依现有 ADMIN/SALES 权限处理保留中的咨询；不连带改变既有询盘 730 天、分析 30 天/13 个月或备份策略。
