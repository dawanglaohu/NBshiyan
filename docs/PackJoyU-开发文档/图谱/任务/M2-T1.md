# M2-T1　扩展产品卡视口与精简信息区

- 所属模块：[[M2]]　产品与 3D：负责产品列表、卡片和详情中的产品表达、直接模型操控、输入冲突处理、触屏与键盘查看、图片回退及带产品上下文的询盘入口。
- 前置依赖：[[M1-T4]]
- 完成后解锁：[[M2-T2]]

## 输入 / 产出

- **输入**：现有ProductGallery/Scene、GET /api/models及11布局
- **产出**：560px自适应大卡和独立模型/动作区域

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 入口：首页products-link→/[locale]/products，数据源GET /api/models及实际模型URL
PC卡最小560px、视口clamp(360px,28vw,440px)，390宽不溢出
名称/必要规格/询盘控件可辨，删重复介绍后操作仍在（[[E-104]]）。2) 标题与按钮独立链接，Canvas内拖动不导航、不提交
从列表category-link进入现有/[locale]/products/[slug]仍受发布开关且返回3D目录，不扩完整PDP（[[E-97]]）。

## 必须处理的边界

- [[E-104]]　产品复位与显示
    - 触发：任意旋转/缩放后点复位，或PC 1440/1920和窄屏查看
    - 期望：以产品已有初始相机/缩放边界作基准，任意操控后复位需回到该值；在1440/1920及窄屏检查完整模型可见、名称及关键操作可辨；移除底部重复介绍后规格与询盘入口仍可见可用，不靠删内容消除裁切。
- [[E-97]]　模型拖动所有权
    - 触发：PC在可见模型视口内pointer-down并拖动，随后指针跨到其他卡片
    - 期望：仅起始模型获得pointer capture并旋转；不触发卡片导航，不切换另一个模型，几何卡片不做hover scale
