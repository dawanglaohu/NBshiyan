# M7-T1　终验公开媒体与3D访客路径

- 所属模块：[[M7]]　集成验收与交付：负责访客跨模块完整路径、后台权限与恢复路径、统计和可靠性完整链路的真实集成验收及交付证据收口；核对本轮复用的恢复来源，不重做 S1 已完成的取回和来源审计，也不自动合并恢复草稿。
- 前置依赖：[[M1-T5]]、[[M2-T5]]、[[M2-T8]]
- 完成后解锁：[[M7-T4]]

## 输入 / 产出

- **输入**：docs/brand-media/static/selected-media-release.json与M1-T6/M1-T9实际发布清单、来源/帧报告、首页现有BRAND_MEDIA及产品GLB链；参考原件仅历史核对
- **产出**：visitor-media-acceptance；真实访客浏览GIF与媒体来源终验报告

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 先核docs/brand-media/static/selected-media-release.json的选定成品
en/ru首页点产品入口，加载真实GLB、拖动/复位并核productSlug和询盘入口
视频用选定v3及对应帧海报，工业场景用确认PNG/GIF，核src/网络文件SHA与选定发布清单一致，不加载旧参考附件/hero。回归暂停、隐藏/减少动态，1920/1440/390无媒体遮挡操作（[[E-21]]、[[E-24]]、[[E-104]]）。2) 复核M1对选定工业GIF的361帧品牌/透视、每帧时序/顺序、30.08秒/无限循环及同尺寸暂停帧
保留原附件SHA，只把旧原件作历史/时序证据，不强制新场景与参考画面相同
不用候选标（[[E-26]]、[[E-30]]）。3) 核实际授权渠道的输入/调用或软件操作/输出/SHA与成品证据
用Dot才核对应调用，未用不能否定已有授权成品。缺必需产物/核验逐项保持未完成，不补造渠道
PNG/GIF的已确认不代表公司工程/事实已完成（[[E-29]]、[[E-111]]）。

## 必须处理的边界

- [[E-104]]　产品复位与显示
    - 触发：任意旋转/缩放后点复位，或PC 1440/1920和窄屏查看
    - 期望：以产品已有初始相机/缩放边界作基准，任意操控后复位需回到该值；在1440/1920及窄屏检查完整模型可见、名称及关键操作可辨；移除底部重复介绍后规格与询盘入口仍可见可用，不靠删内容消除裁切。
- [[E-111]]　公司图稿、可编辑源工程及品牌来源可追溯
    - 触发：公司区块图稿缺真实可编辑工程/Web图、来源或实际网页消费
    - 期望：以已确认新素材复用/排版1–2幅公司图，逐件交真实可编辑工程/Web图/enru alt，登记选定输入path/SHA/用途、己方事实或示意依据、现用master、工程/导出SHA、实际软件版本/渠道/操作及网页位置。平面PNG/GIF不冒充工程；缺任一必需项未完成，素材已确认不等于工程或事实齐全。页面实际加载匹配图稿且主体完整，不扩大为25页目录或无依据厂房/证照。
- [[E-21]]　主页视频、JPG、GIF加载与控制
    - 触发：首屏正常访问
    - 期望：用选定v3成片（约12.3秒，精确时长/帧数取成片记录）静音行内播放，提供可操作播放/暂停；JPG海报必须取该成片。自动播放受阻保留此海报和主动播放入口。
- [[E-24]]　主页视频、JPG、GIF加载与控制
    - 触发：用户暂停、模块离开视区或页面转到后台
    - 期望：保持明确暂停状态，恢复可见时不擅自覆盖用户的暂停选择。
- [[E-26]]　自己的Logo与参考PDF事实边界
    - 触发：选定PNG/GIF的任一帧或透视平面发现旧品牌/漏标
    - 期望：以已确认工业素材为当前输入并保留原件，逐帧核首尾/转场/透视/遮挡；仅残留缺陷需定点清理并用现用PackJoyU覆盖，不只改封面或模糊旧标，不从历史参考重做场景。
- [[E-29]]　自己的Logo与参考PDF事实边界
    - 触发：复用已确认素材、补齐图稿工程或实际采用授权工具制作
    - 期望：先核选定成品及真实渠道记录；实际使用Dot才核其调用/操作/输出，不因未用Dot否定其他授权成果。缺必需制作/工程/成品/核验才逐项记未完成，不伪称调用或用计划代替产物。
- [[E-30]]　自己的Logo与参考PDF事实边界
    - 触发：选定工业GIF的时序、稳定性或品牌覆盖核验失败
    - 期望：依已确认GIF/动画记录逐帧核时刻、顺序、30.08秒及无限循环，首尾/品牌/透视/遮挡恢复无漏标或修订新增错位抖动。缺陷只修当前副本，失败副本标未完成并排除发布；原JPG/GIF仅留历史/时序/制作回滚，绝不作网页回退src，不以原参考画面逼重做新场景。
