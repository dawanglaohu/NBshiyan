# M7-T1　终验公开媒体与3D访客路径

- 所属模块：[[M7]]　集成验收与交付：负责访客跨模块完整路径、后台权限与恢复路径、统计和可靠性完整链路的真实集成验收及交付证据收口；核对本轮复用的恢复来源，不重做 S1 已完成的取回和来源审计，也不自动合并恢复草稿。
- 前置依赖：[[M1-T5]]、[[M2-T5]]、[[M2-T8]]
- 完成后解锁：[[M7-T4]]

## 输入 / 产出

- **输入**：已交付发布副本/品牌来源记录、首页和产品GLB链
- **产出**：visitor-media-acceptance；真实访客浏览GIF与媒体来源终验报告

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) en/ru首页点击产品入口并加载真实GLB，实际拖动与复位后核productSlug和可见询盘入口
视频/GIF暂停、隐藏页和减少动态效果回归，1920/1440/390操作区不受媒体遮挡（[[E-21]]、[[E-24]]、[[E-104]]）。2) 复核M1逐帧报告与原件哈希：361帧品牌/透视覆盖、原时序/30.08秒/循环保持且不把候选标当正式标（[[E-26]]、[[E-30]]）。3) 对GPT Dot制作逐件核实际调用记录、远程软件操作与输出文件
不可达的文件逐项记尚未执行及实施任务并保持未完成，不以文字冒称已调用或换标完成（[[E-29]]）。

## 必须处理的边界

- [[E-104]]　产品复位与显示
    - 触发：任意旋转/缩放后点复位，或PC 1440/1920和窄屏查看
    - 期望：以产品已有初始相机/缩放边界作基准，任意操控后复位需回到该值；在1440/1920及窄屏检查完整模型可见、名称及关键操作可辨；移除底部重复介绍后规格与询盘入口仍可见可用，不靠删内容消除裁切。
- [[E-21]]　主页视频、JPG、GIF加载与控制
    - 触发：首屏正常访问
    - 期望：12.27 秒视频以静音行内方式展示并提供可操作的播放/暂停控件，JPG 作为海报；若自动播放被阻止则保留海报和主动播放入口。
- [[E-24]]　主页视频、JPG、GIF加载与控制
    - 触发：用户暂停、模块离开视区或页面转到后台
    - 期望：保持明确暂停状态，恢复可见时不擅自覆盖用户的暂停选择。
- [[E-26]]　自己的Logo与参考PDF事实边界
    - 触发：JPG 或 GIF 任一帧、任一透视平面存在旧品牌
    - 期望：保留原件，对发布副本逐帧跟踪清理并以 PackJoyU 标识替换，抽帧核查首尾帧、转场和遮挡恢复处，不只改封面或模糊旧 logo。
- [[E-29]]　自己的Logo与参考PDF事实边界
    - 触发：GPT Dot 工具可达并实际执行远程软件制作
    - 期望：留存调用记录、软件操作与输出文件证据，再检查成品；工具不可达时逐项登记“尚未执行”和具体实施任务，不冒称已调用或已完成素材替换。
- [[E-30]]　自己的Logo与参考PDF事实边界
    - 触发：替换后的 GIF 不能保持原时序、画面稳定或正确品牌覆盖
    - 期望：沿原 GIF 时间轴逐帧对照发布副本：帧呈现时刻、顺序与循环总时长保持不变；每次旧品牌出现、透视变化、转场及遮挡后再现均由 PackJoyU 完整覆盖，不出现替换新增的错位、漏标或抖动。任一项失败则继续修复该发布副本，将文件标为未完成且不纳入发布成品；原始 JPG/GIF 始终保留用于回退。
