# M2-T7　把真实GLB生命周期接入分析采集

- 所属模块：[[M2]]　产品与 3D：负责产品列表、卡片和详情中的产品表达、直接模型操控、输入冲突处理、触屏与键盘查看、图片回退及带产品上下文的询盘入口。
- 前置依赖：[[M2-T4]]、[[M2-T6]]、[[M5-T6]]、[[M5-T7]]、[[M5-T3]]
- 完成后解锁：[[M2-T8]]、[[M6-T1]]、[[M7-T3]]

## 输入 / 产出

- **输入**：model-event-rules、model-fallback、analytics-ingest与analytics-consent-ui
- **产出**：model-events；页面/产品访问与真实GLB start/terminal生产者接线

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 真浏览器产品卡发起GLB后POST /api/analytics/events分别保存产品访问、model_view_start及成功/失败
仅进入产品路由且没有真实GLB加载尝试时无start
可视区自动加载或主动操作确实发起GLB时均产生start，不要求额外激活点击
未同意/拒绝分析时模型仍可用且无分析请求（[[E-42]]、[[E-46]]）。2) 分别注入GLB下载失败/WebGL不支持/context lost/poster或FoldBox，仅对应产品静态回退、重试及询盘可用
poster/演示无GLB success
同viewId最多一种终态，新实际重试按规则新viewId（[[E-103]]）。3) 成功/失败/超时两次尝试与切卡取消逐项核关联及真实durationMs，分母仅同意后真实start、timeout为failure、平均耗时带samples且无样本null，不补拒绝样本（[[E-63]]）。

## 必须处理的边界

- [[E-103]]　真实模型失败与统计
    - 触发：GLB下载失败、WebGL不支持、context lost或只能展示海报/FoldBox演示
    - 期望：分别注入GLB下载失败、不支持WebGL、context lost、仅poster/FoldBox，检查对应产品静态回退、重试和询盘；同viewId最多一个终态，poster/程序演示均不发GLB success。真实模型重试若新建尝试按既定viewId规则处理。
- [[E-42]]　C-05 分析采集、去重与保留期
    - 触发：用户尚未允许或拒绝分析
    - 期望：不生成或保存分析标识、不发分析事件，网站与 3D 功能仍可用；看板明确只覆盖授权浏览器，不将缺失授权样本补成全站人数。
- [[E-46]]　C-05 分析采集、去重与保留期
    - 触发：仅进入产品路由、可视区或主动操作实际发起GLB加载，或加载失败
    - 期望：产品页访问与真实模型加载发起分别记录：仅路由访问但尚无加载尝试不发start，可视区自动加载或主动操作确实发起GLB就按viewId发start，不要求额外激活点击；成功/失败按实际终态并绑定服务端认可产品标识，失败和poster/FoldBox不算GLB成功。
- [[E-63]]　运维指标扩展及角色权限
    - 触发：3D 加载有成功、失败、超时或没有样本
    - 期望：引用09节既定口径：分母为获同意后真实 model_view_start；同 viewId 最多一个 success/failure 终态，超时记 failure；终态 durationMs 的有效样本算平均耗时并带 samples，无样本为 null，零成功且有样本才为0%，拒绝分析样本不补分母。
