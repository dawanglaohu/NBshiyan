# M1-T4　接好首页视频与分区JPG/GIF场景

- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T6]]、[[M1-T7]]、[[M1-T8]]
- 完成后解锁：[[M1-T5]]、[[M2-T1]]

## 输入 / 产出

- **输入**：brand-media、visual-components、client-api-foundation与现有首页SSR布局
- **产出**：home-media；现有主页/公共壳中的视频与分区品牌场景

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 点击字标home-link→/[locale]、products-link→产品、contact-link→联系，并核SSR来源与GET /api/models
12.27秒视频muted/playsinline且播放/暂停可点击，阻止autoplay后保留海报及播放入口，解码失败/减少动态效果显示语义JPG而不强制持续播放（[[E-21]]、[[E-22]]）。2) 城市JPG/GIF位于产品区后
网络断言接近视区300px前没有GIF下载，进入后才加载
点击暂停、离开视区、后台页均切同尺寸静帧，恢复可见不覆盖用户暂停（[[E-23]]、[[E-24]]）。3) 1440/1920/390逐项测媒体宽高比与源一致，媒体DOM矩形不与导航/正文/3D操作区的可点击矩形相交，渲染媒体的完整源图像四角及主体均在容器内
不得删主体或控件通过，保留按钮动作真实GIF（[[E-25]]）。

## 必须处理的边界

- [[E-21]]　主页视频、JPG、GIF加载与控制
    - 触发：首屏正常访问
    - 期望：12.27 秒视频以静音行内方式展示并提供可操作的播放/暂停控件，JPG 作为海报；若自动播放被阻止则保留海报和主动播放入口。
- [[E-22]]　主页视频、JPG、GIF加载与控制
    - 触发：用户开启减少动态效果、视频解码失败或加载超时
    - 期望：默认展示 JPG，提供用户主动播放入口，不持续强制播放。
- [[E-23]]　主页视频、JPG、GIF加载与控制
    - 触发：30.08 秒 GIF 场景模块尚未接近可视区
    - 期望：不提前下载整段 GIF；进入可视范围后加载，并提供“暂停”切换到同尺寸静帧的控制。
- [[E-24]]　主页视频、JPG、GIF加载与控制
    - 触发：用户暂停、模块离开视区或页面转到后台
    - 期望：保持明确暂停状态，恢复可见时不擅自覆盖用户的暂停选择。
- [[E-25]]　主页视频、JPG、GIF加载与控制
    - 触发：移动端或较窄窗口
    - 期望：列明在已定义的 PC 1440/1920 和窄屏验收尺寸检查：容器宽高比与素材一致，导航、正文及 PC 3D 控件的可见点击区域不被媒体覆盖，裁切后仍显示原图主体；不得以删除主体或操作区域通过检查。
