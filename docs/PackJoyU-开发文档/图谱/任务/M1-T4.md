## 实施沉淀

<!-- notes:begin -->
暂停静帧必须用 `docs/brand-media/static/held/packjoyu-industrial-city-v3-loop-poster.png`（1384×720）。公开的 `packjoyu-industrial-city-v3.png` 是 1737×905，预览 GIF 是 960×500，两张都不能和全尺寸 GIF 放进同一个框。首页通过静态 import 把这张海报交给 `BrandScene`；可选 `stillSrc` 缺省时保留公开 PNG 回退，首页显式传入同尺寸海报，不使用该回退作为暂停帧。

GIF 的下载和播放分开。`admitted` 在区块进入视口上下 300px 时变为真，这时用 `Image` 预取，不把地址写进页面上的 img。页面上的 GIF `src` 只在 `showGif` 时出现：已准入、与实际视口相交、页面可见，且 `userPaused` 为假。完全离开视口时卸下 GIF，留下同尺寸静帧，不改 `userPaused`。回到视口后，用户已经暂停的动画保持静帧。

页面隐藏走 `visibilitychange`。浏览器冻结页面前，`freeze` 在同一轮提交静帧，冻结之后不会再绘制。`resume` 按当时的 `visibilityState` 决定是否恢复。减少动态效果默认停在静帧，[按钮（Button）](https://vibe-hub.org/button) 仍可主动播放；点击时区块还在视口外，要等它进入视口才挂 GIF。

播放、暂停和跳过消费共享 `Button` 的 `context="public"`。边框、圆角、阴影和触控尺寸来自 `tokens.css` 的 `--pj-border-width`、`--pj-radius`、`--pj-shadow`、`--pj-touch-target`，键盘焦点使用 `--pj-focus-width` 与 `--pj-accent`。

`src/lib/navigation/routes.ts` 登记本层 home、products、contact 的路径和入口 ID。`SiteHeader` 读取这三行，链接经 `src/i18n/navigation` 的 `Link` 带上语言前缀。about 仍由 M1-T5 的字面路径控制，本层不补后台，也不另拉目录。

`HeroVideo` 在减少动态效果或省流量时不自动挂视频，`setManualOffer(true)` 保留主动播放入口。`tests/hero-video.test.ts` 当前用单行源码匹配保护该分支，调整写法时需同步保留等价行为断言。自动播放被拒绝、解码失败，或 15 秒内没有 `playing`，都卸下 [视频（Video）](https://vibe-hub.org/video) 并回到海报，不自动重试；用户仍可再次主动播放。

开发服务的内容安全策略不允许 `unsafe-eval`，会阻止 `next dev` 客户端脚本执行，因此媒体交互须用生产构建核验。Windows 的 `output: standalone` 依赖复制可能因 symlink 权限报 EPERM；已编译 `.next` 可供 `next start` 局部检查，但不能据此宣称完整构建或 standalone 验收通过。

真实后台页验收使用独立 Chrome，在目标页调试器断开期间最小化窗口或切换标签页；原生可信 `visibilitychange` 使 GIF 切静帧，恢复后保留用户暂停。`_run/M1-T4.native-visibility.evidence.json` 保存逐步状态。自动化中的 freeze/resume 事件派发只核处理器分支，不充当真实标签页证据。距离断言使用即时滚动，焦点样式由真实 Shift+Tab/Tab 验证，避免平滑滚动与非标准 focus 参数影响结果。
