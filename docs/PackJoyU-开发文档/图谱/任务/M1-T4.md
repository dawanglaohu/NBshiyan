## 实施沉淀

<!-- notes:begin -->
暂停静帧必须用 `docs/brand-media/static/held/packjoyu-industrial-city-v3-loop-poster.png`（1384×720）。公开的 `packjoyu-industrial-city-v3.png` 是 1737×905，预览 GIF 是 960×500，两张都不能和全尺寸 GIF 放进同一个框。首页通过静态 import 把这张海报交给 `BrandScene`；没传 `stillSrc` 时组件仍回退到公开 PNG，这样既有静态渲染测试继续看到那张 PNG，页面本身不会拿它当暂停帧。

GIF 的地址只能在 `IntersectionObserver` 的 `rootMargin: 300px` 成立之后写进 `src`。先写上地址再藏起来，浏览器照样会下载。

用户暂停和「离开视区 / 页面隐藏」是两套状态。离开或隐藏只卸下 GIF；回到可见区域时，只有 `userPaused` 仍为假才重新挂上。减少动态效果默认停在静帧，[按钮（Button）](https://vibe-hub.org/button) 还在，点下去才播放，回来也不会把这次选择盖掉。

`HeroVideo` 里 `if (env.reducedMotion || env.saveData) return;` 必须留在同一行。`tests/hero-video.test.ts` 用这行源码锁定「减少动态效果不挂视频」。播放入口靠这行前面的 `setManualOffer(true)`。删掉这行会让该测试变红，也会让减少动态效果重新自动播放。自动播放被拒绝、解码失败，或 15 秒内没有 `playing`，都卸下 [视频（Video）](https://vibe-hub.org/video) 并回到海报，之后不再调用 `play()`。

开发服务的内容安全策略不允许 `unsafe-eval`，`next dev` 的客户端脚本不会执行，播放按钮和 GIF 都不会出现。这条验收要在生产构建上用 `next start` 看。Windows 上 `output: standalone` 复制依赖时会因无法创建 symlink 而 EPERM，页面本身已经编完，不能把这一步当成页面没编出来。
<!-- notes:end -->
