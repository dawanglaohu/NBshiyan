# M4-T7　注册聊天保留候选与默认拒绝真实清理

- 所属模块：[[M4]]　第一方人工咨询：负责访客必要会话、人工消息与离线留言、ADMIN/SALES 收件箱和回复、未读、失败草稿与幂等重试，并保存真实收件和通知结果。
- 前置依赖：[[M4-T3]]、[[M5-T1]]、[[M5-T8]]
- 完成后解锁：[[M4-T13]]、[[M7-T4]]

## 输入 / 产出

- **输入**：聊天活动/retainUntil、M5固定job和生产清理另行授权边界。
- **产出**：chat-retention每日cron、只读候选计数、策略version、默认dry-run与授权门禁。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 调用方/接线点：每日真实cron POST /api/admin/cron/operations(jobKey=chat-retention)→registry→候选查询
无另行保留授权或开关未启用时仅dry-run，真实删除请求拒绝且deletedCount=0，文档/模型/派发不能作授权
隔离库前后行内容hash不变（[[E-88]]）。2) 查询候选按90d retainUntil，7d/30d cookie失效不提前选中期内内容，read/轮询/通知不延长期限
结果只计数/安全时间无正文/email，既有询盘730d/分析/备份不纳入查询（[[E-85]]、[[E-86]]）。

## 必须处理的边界

- [[E-85]]　聊天凭据及数据保留期限
    - 触发：cookie 闲置达到 7 天、签发达到 30 天绝对上限或被撤销
    - 期望：服务端拒绝该凭据访问旧会话，浏览器可建立新咨询；仅填写相同邮箱不能找回旧会话，cookie 与其前端副本均不存 PII。
- [[E-86]]　聊天凭据及数据保留期限
    - 触发：隐藏标签页仍有轮询，或仅刷新访问但没有成功收发咨询消息
    - 期望：这些行为不推迟消息/邮箱的 90 天保留截止；咨询活动以成功保存的访客消息或人工回复为准，不把通知重试、投递回执或读状态更新当作新咨询。
- [[E-88]]　聊天凭据及数据保留期限
    - 触发：本轮文档被生成或实施者拿到派发任务
    - 期望：新增纯授权门禁的可测表述：生产真实清理默认关闭且 dry-run 为默认模式；不存在另行明确的保留策略授权时，启用或请求真实删除必须拒绝且删除计数为0，可返回候选计数/未启用状态。文档、任务派发、模型或代理结论均不能充当授权。只用隔离数据验证，不触碰生产/恢复/备份现有数据。
