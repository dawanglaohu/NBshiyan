# M6-T7　完成看板逐源状态与故障呈现

- 所属模块：[[M6]]　业务与运维看板：负责按角色查询并解释统计结果，读取询盘、聊天、接口错误、邮件、存储和备份的真实来源，区分数据时间、零值、无数据、未接入、失败和旧值。
- 前置依赖：[[M6-T4]]、[[M6-T2]]、[[M6-T5]]、[[M6-T3]]
- 完成后解锁：[[M7-T3]]、[[M7-T7]]

## 输入 / 产出

- **输入**：stats-base-ui、business/reliability/ops来源及10状态DTO
- **产出**：stats-ui；SourceCard状态、独立时间、趋势覆盖与安全重试

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 从/admin/stats的真实GET响应分别验成功0、no_data、not_connected、无旧值query_failed、有旧值stale、单来源失败和重算partial
每源保留原dataThrough/lastSucceededAt，失败刷新不更新旧数据时间，其他指标可继续读取（[[E-49]]、[[E-50]]、[[E-51]]、[[E-52]]、[[E-53]]、[[E-67]]）。2) 查询成功但没有事件接收链路证据时，仅显示实际配置/最近接收/查询结果与未知或最后已知时间
零流量不产生健康心跳或全链路正常徽标（[[E-54]]）。3) 三尺寸真实页面复验D1-D6和可辨时间/来源标签、键盘刷新，保存GIF
手动刷新仅GET stats，不调cron/备份/发信。

## 必须处理的边界

- [[E-49]]　C-06 看板数据时间与异常状态
    - 触发：数据源已接通、查询成功且所选日确有 0 条符合口径的事件
    - 期望：展示数值 0、查询成功时间及授权统计范围，不伪报查询失败或尚未接入。
- [[E-50]]　C-06 看板数据时间与异常状态
    - 触发：首次启用、数据源未接通或尚无可查询数据
    - 期望：分别显示尚无数据或未接入及具体来源，不以 0 冒充真实统计，不把“今日无事件”单独判作采集故障。
- [[E-51]]　C-06 看板数据时间与异常状态
    - 触发：查询失败且已有上次成功快照
    - 期望：保留旧值并显著标注旧值时间、当前失败及重试入口；不能刷新时间后让旧值看似刚更新。
- [[E-52]]　C-06 看板数据时间与异常状态
    - 触发：查询失败且没有成功快照
    - 期望：显示错误与重试，不生成默认 0 或演示数字；错误信息不向业务角色暴露凭据、堆栈或连接串。
- [[E-53]]　C-06 看板数据时间与异常状态
    - 触发：面板内不同来源的更新速度或失败状态不同
    - 期望：每个指标保留自己的数据时间与状态，页面总刷新成功不覆盖局部失败。
- [[E-54]]　C-06 看板数据时间与异常状态
    - 触发：查询成功但事件接收链路健康尚无法实证
    - 期望：仅报告实际观测到的配置、最近接收和查询状态，显示未知或最后已知时间，不从无流量推断全链路健康。
- [[E-67]]　运维指标扩展及角色权限
    - 触发：任一附加来源中断或无数据
    - 期望：该卡独立显示错误、旧值、未知或未接入；其他真实指标仍可查询，避免单个辅助来源拖垮整张看板。
