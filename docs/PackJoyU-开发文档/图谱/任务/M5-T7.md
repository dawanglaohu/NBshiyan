## 实施沉淀

<!-- notes:begin -->
- 分析身份只存在于 Path 为 `/api/analytics` 的 HttpOnly cookie。页面脚本清不掉它，撤回必须打到同意端点。采集器离线不能把这次撤回也断掉，否则 cookie 还在，恢复在线后旧队列或下一次导航会继续记。
- 本地偏好 `pj-consent` 不是分析身份。文档第一次导航时若其中 `analytics === true`，只恢复采集并发出这次 `page_view`，不另 POST 同意。cookie 缺失或过期时，事件批 403 停止采集，未签发的浏览器不会留在采集状态。
- 在途的 false 还没返回时，后到的同意只写入 `nextIntent`。再次撤回若发现 `flightWant === false`，先把 `nextIntent` 置为 null 再返回，避免这次 false 结束后把同意发出去。
- 窄屏确认 toast 自己写入 `--pj-toast-h`。横幅关掉后 `--pj-consent-h` 会归零，悬浮按钮不能只靠横幅变量。`--fab-h` 和页脚留白不随 toast 改变。
- 按下同意时已经打开的页面不补发。验收要的是其后的导航。补发当前页会把同意前的停留算成访问。
- 同一 `navigationId` 的重试必须沿用原来的 `eventId` 和发生时间。改写时间会变成另一条语义键。
- 隐私页的 90 天咨询和 13 个月聚合不要改去读保留作业的默认 730 天，也不要把 dry-run 环境开关的当前布尔值印出来。未设置该开关时布尔值是 false，和“默认 dry-run、实际删除另需授权”不是同一句话。
- `privacyIndexable` 仍看完整度和占位文案。多出来的账本文案不改变 noindex。
- 英文和俄文产品页要在各自语言已经生效的文档里做客户端路径更新。在英文文档里直接改成俄文路径时，当前语言前缀剥不掉俄文 slug，内部 key 对不上。
