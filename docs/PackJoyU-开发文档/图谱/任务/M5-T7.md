# M5-T7　接通同意UI、页面事件与隐私说明

- 所属模块：[[M5]]　同意与统计账本：负责分析同意、匿名浏览器与事件标识、采集准入和去重、站点统计时区设置、日与产品聚合、原始与聚合保留及可重算边界，产出真实访问和 3D 统计。
- 前置依赖：[[M5-T2]]、[[M5-T6]]、[[M1-T8]]、[[M1-T7]]、[[M5-T9]]
- 完成后解锁：[[M2-T7]]、[[M5-T8]]

## 输入 / 产出

- **输入**：analytics-consent-api、analytics-ingest、client-api-foundation及现有footer偏好入口；analytics-settings-domain的公开时区及现有en/ru隐私文案
- **产出**：analytics-consent-ui、analytics-page-events；串行同意写与页面生产者；analytics-privacy-copy隐私页面及匿名浏览器/保留说明

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 用空白浏览器context点击footer analytics-preferences，断言偏好面板可见
在未选择及点击拒绝两种状态，cookie及浏览器存储无分析身份、POST /api/analytics/events次数为0，产品导航和模型操作控件仍可点击响应。点击同意后POST /api/analytics/consent的analytics=true，收到有效签名cookie
随后导航产生page_view，响应acceptedIds含本eventId，同navigationId重试后数据库仍仅一条（[[E-42]]）。2) 在事件发送前断网形成待发队列，再点击撤回：本地分析身份与待发条目数均为0，恢复网络后不发该队列
继续导航不发events，cookie已清，清cookie后无有效cookie的旧待发事件请求403。另延迟实际true请求响应后点击false，断言写请求串行、最后为false，全部响应结束后cookie为空、队列为0且不恢复采集，不补发撤回期间访问（[[E-43]]）。3) 1920×1080、1440×900、390×844记录请求及操作GIF
computed style的边界宽度=2px、圆角=0px、强调色等于11节token
Tab可聚焦各命名控件并以Enter/Space操作，每个触屏目标实测≥44 CSS px。4) 点击footer privacy-link→/[locale]/privacy，en定义文本包含“anonymous browsers that consented to analytics”，ru包含“анонимных браузеров, разрешивших аналитику”
文案不作唯一真人/跨设备识别宣称。隔离测试分别换设备context、清标识、换浏览器，查询后端确认可形成新browserHash，报告仅记不同与否、不输出原值（[[E-45]]）。5) 隐私页的必要聊天、分析同意、清理状态分区分别可见
期限显示来自配置的聊天cookie7天闲置/30天绝对、咨询90天、原始分析30天/聚合13个月，站点IANA文本等于SiteSetting值
默认清理状态明确显示未启用/dry-run及实际清理须另行授权，不把文档/派发视为授权
robots/noindex仍按既有完整度开关判定。

## 必须处理的边界

- [[E-42]]　C-05 分析采集、去重与保留期
    - 触发：用户尚未允许或拒绝分析
    - 期望：不生成或保存分析标识、不发分析事件，网站与 3D 功能仍可用；看板明确只覆盖授权浏览器，不将缺失授权样本补成全站人数。
- [[E-43]]　C-05 分析采集、去重与保留期
    - 触发：用户撤回分析同意
    - 期望：停止采集，丢弃尚未发送的分析事件并清除本地分析标识；不能事后补发撤回期间的访问。
- [[E-45]]　C-05 分析采集、去重与保留期
    - 触发：同一人换设备、清除标识或使用不同浏览器
    - 期望：在访客数的定义/提示处写明“已同意分析的匿名浏览器数”；分别用换设备、清标识、换浏览器验证可能形成新 browserHash，不出现“唯一真人”或跨设备识别宣称。
