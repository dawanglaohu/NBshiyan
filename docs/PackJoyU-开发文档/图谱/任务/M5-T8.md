- 所属模块：[[M5]]　同意与统计账本：负责分析同意、匿名浏览器与事件标识、采集准入和去重、站点统计时区设置、日与产品聚合、原始与聚合保留及可重算边界，产出真实访问和 3D 统计。
- 前置依赖：[[M5-T1]]、[[M5-T3]]、[[M3-T1]]、[[M5-T7]]、[[M3-T14]]
- 完成后解锁：[[M4-T1]]、[[M4-T4]]、[[M4-T7]]、[[M4-T12]]、[[M5-T4]]、[[M5-T11]]、[[M6-T3]]、[[M7-T7]]

- **输入**：job-leases、analytics-aggregate与M3共享HTTP防护
- **产出**：job-foundation、analytics-aggregate-runtime；固定registry、POST /api/admin/cron/operations及真实cron

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) composition只注册已实现analytics-aggregate，deploy/cron.nbshiyan每5分钟POST /api/admin/cron/operations
固定key/Bearer常量时间校验，未知key/无凭据拒绝，不允许任意脚本。2) 真调度在重启后实际运行并提交JobState/watermark，batch≤500、55s截止、旧代次不能覆盖
停cron/失败保持上次成功watermark并显示安全状态NEVER/FAILED/旧值，不凭路由存在或手动调用宣称刚更新（[[E-81]]、[[E-84]]）。3) 浏览器同意后同日同浏览器完成两次页面访问并刷新/重试同eventId，实际job后UV仍1、真实新访问PV增加且重复事件不增加（[[E-44]]）
看板GET不触发任务，通知/邮件由M4注册，不导入未来服务或登记空实现。4) 隔离服务使用可控时钟经事件HTTP入口分别提交now-48h-1ms、now-48h、now+5min、now+5min+1ms：超界两项返回event_time_out_of_range且无记录，边界两项可准入
准入未来事件在实际聚合作业时钟到其occurredAt前不计入，到时后才计入。48h内迟到事件仅重算仍具完整原始覆盖的所属日，已关闭/超窗口历史不受任意客户端时间污染
完整覆盖外保留原聚合并标partial/unavailable，不以残片写小或造未来日（[[E-60]]）。

## 必须处理的边界

- [[E-44]]　C-05 分析采集、去重与保留期
    - 触发：同一授权浏览器刷新或重试同一事件
    - 期望：当日授权访客按浏览器标识去重，同一事件 ID 不重复计数；真实的新页面访问可增加 PV，UV 不随刷新增加。
- [[E-60]]　今日统计的站点时区与历史重算
    - 触发：浏览器上传未来或明显过期的事件时间
    - 期望：直接引用09节既定 now-48h≤occurredAt≤now+5min：超界拒绝，准入的未来事件到其真实时间后才参与聚合；闭区间历史按原始完整覆盖和既定迟到窗口处理，禁止任意客户端时间污染未来日或已关闭区间。
- [[E-81]]　分析聚合与水位发布
    - 触发：两个调度实例重叠，或旧任务超时后晚于新任务提交
    - 期望：使用数据库互斥或带代次的租约及提交校验，旧任务不能覆盖新结果；一次事务替换整组目标日数据并提交 watermark，进程中断保留上次完整结果。
- [[E-84]]　分析聚合与水位发布
    - 触发：聚合入口存在但 cron 未注册、cron 停止或最近运行失败
    - 期望：不宣称已接入或刚更新，展示真实最近成功 watermark 与旧值状态；实施任务必须包含真实五分钟调度注册及重启后运行证据，不能只验证手动调用接口。
