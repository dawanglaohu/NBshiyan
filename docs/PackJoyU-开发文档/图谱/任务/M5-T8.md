## 必须处理的边界

- [[E-44]]　C-05 分析采集、去重与保留期
    - 触发：同一授权浏览器刷新或重试同一事件
    - 期望：当日授权访客按浏览器标识去重，同一事件 ID 不重复计数；真实的新页面访问可增加 PV，UV 不随刷新增加。
- [[E-60]]　今日统计的站点时区与历史重算
    - 触发：浏览器上传未来或明显过期的事件时间
    - 期望：直接引用09节既定 now-48h≤occurredAt≤now+5min：超界拒绝，准入的未来事件到其真实时间后才参与聚合；闭区间历史按原始完整覆盖和既定迟到窗口处理，禁止任意客户端时间污染未来日或已关闭区间。
- [[E-81]]　分析聚合与水位发布
    - 触发：两个调度实例重叠，或旧任务超时后晚于新任务提交
    - 期望：使用数据库互斥或带代次的租约及提交校验，旧任务不能覆盖新结果；一次事务替换整组目标日数据并提交 watermark，进程中断保留上次完整结果。
- [[E-84]]　分析聚合与水位发布
    - 触发：聚合入口存在但 cron 未注册、cron 停止或最近运行失败
    - 期望：不宣称已接入或刚更新，展示真实最近成功 watermark 与旧值状态；实施任务必须包含真实五分钟调度注册及重启后运行证据，不能只验证手动调用接口。
