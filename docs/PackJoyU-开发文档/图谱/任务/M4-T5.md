# M4-T5　接通访客聊天打开与消息编辑器

- 所属模块：[[M4]]　第一方人工咨询：负责访客必要会话、人工消息与离线留言、ADMIN/SALES 收件箱和回复、未读、失败草稿与幂等重试，并保存真实收件和通知结果。
- 前置依赖：[[M4-T10]]、[[M4-T15]]、[[M1-T8]]、[[M5-T6]]、[[M5-T7]]
- 完成后解锁：[[M2-T8]]、[[M4-T9]]

## 输入 / 产出

- **输入**：M4必要session/首消息/追加/读取API，M1 UI/client基础、既有InquiryWizard。
- **产出**：ContactChatEntry/ChatContainer/Composer/MessageList，主动打开、首次/后续提交和明确Refresh messages读取；自动同步另由M4-T9交付。 成功收件后的同意门控chat_start生产者，复用M5客户端队列与当前navigationId。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 入口：主页Request a quote→/[locale]/contact→Contact a person（contact-human-chat）
点开才POST /api/chat/session
Send message（chat-send）调用POST /api/chat/conversations或对应messages，数据源还含GET /api/chat/conversations/[id]
实际点击断言id/seq/receivedAt，成功前不显示received（[[E-31]]）。2) 服务可达但无人值守显示Offline message，无在线灯，保存成功文案Received, awaiting human handling且无即时答复承诺
email空/省略可发、非法/超长错误保留消息，关闭未发送草稿不持久化（[[E-17]]、[[E-36]]、[[E-38]]、[[E-39]]）。3) 首次cookie401/404或关闭线程时停止旧提交并显示Start a new conversation按钮，不自动把旧草稿发新会话
拒分析照常咨询且网络无第三方脚本（[[E-40]]、[[E-85]]）。 按11节唯一minimalist-flat，在实际服务1920×1080、1440×900、390×844记录GIF与computed style：2px黑边、0圆角、无阴影、强调色#b45700
后台逐页以work/form/card、density7/gutter16/gap16/pad16运行D1–D6和overflow探针。label与键盘焦点可达，触屏控件点击框至少44px。
4) 当前导航首次新咨询收件成功且当时有效同意后，POST /api/analytics/events发kind=chat_start、原navigationId、随机eventId/occurredAt及可选已发布productSlug/净化path
同次成功回调/响应重试复用eventId且只计一次。回复、失败、仅开窗口、拒绝/撤回及后补同意不补发历史
事件不含email/body/会话或消息ID/cookie凭据。真实聊天→事件→聚合chatStarts有端到端断言，必要聊天不依赖分析同意（[[E-40]]、[[E-47]]）。

## 必须处理的边界

- [[E-17]]　在线聊天实现路线
    - 触发：没有在线运营、服务暂时不可达或网络中断
    - 期望：明确显示离线留言或待重试状态，持久化成功后才承诺收件；失败不伪装已送达。
- [[E-31]]　C-01 人工聊天收件与回复入口
    - 触发：访客提交消息且服务端持久化成功
    - 期望：返回稳定的会话与消息标识并显示“已接收”，运营收件箱能读取；数据库写入失败则保留待重试，不显示已接收或客服已读。
- [[E-36]]　C-02 离线留言与发送失败恢复
    - 触发：客服离线而服务端可达
    - 期望：明确显示离线留言，不显示有人在线；成功保存后显示“已接收，等待人工处理”，不承诺即时回复。
- [[E-38]]　C-02 离线留言与发送失败恢复
    - 触发：网络中断且尚未保存
    - 期望：消息与可选邮箱只留在当前标签页内存，可重试并提供现有联系邮箱入口；刷新、关闭或崩溃后不承诺恢复草稿，也不写入 localStorage 或日志。
- [[E-39]]　C-02 离线留言与发送失败恢复
    - 触发：访客主动提供空邮箱、非法格式或超长联系方式
    - 期望：镜像10节已定字段：email 可省略；填写时 trim 后≤254、单个合法邮箱、不接收显示名/CRLF；空值按不填处理，非法或过长返回字段错误并保留当前标签页原消息，不升级为已验证身份或投递保证。
- [[E-40]]　C-02 离线留言与发送失败恢复
    - 触发：访客拒绝分析但主动打开第一方人工聊天
    - 期望：允许完成必要咨询，不创建分析标识或加载第三方聊天脚本，聊天必要会话与分析同意分开处理。
- [[E-47]]　C-05 分析采集、去重与保留期
    - 触发：客户端伪造产品、超长字段、任意事件类型或重放事件
    - 期望：服务端按白名单、字段长度与产品有效性校验并限制滥发，拒绝异常记录；分析记录不存原始 IP、跨站指纹、邮箱、聊天正文或含敏感查询参数的完整 URL。
- [[E-85]]　聊天凭据及数据保留期限
    - 触发：cookie 闲置达到 7 天、签发达到 30 天绝对上限或被撤销
    - 期望：服务端拒绝该凭据访问旧会话，浏览器可建立新咨询；仅填写相同邮箱不能找回旧会话，cookie 与其前端副本均不存 PII。
