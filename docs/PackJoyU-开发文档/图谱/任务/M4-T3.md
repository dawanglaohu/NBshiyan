# M4-T3　查询当前授权运营的收件箱及读状态

- 所属模块：[[M4]]　第一方人工咨询：负责访客必要会话、人工消息与离线留言、ADMIN/SALES 收件箱和回复、未读、失败草稿与幂等重试，并保存真实收件和通知结果。
- 前置依赖：[[M4-T2]]、[[M3-T1]]
- 完成后解锁：[[M4-T6]]、[[M4-T7]]、[[M4-T11]]

## 输入 / 产出

- **输入**：真实聊天事实与M3当前角色；09/10共享聊天范围及运营read cursor。
- **产出**：GET /api/admin/chat/conversations、GET /api/admin/chat/conversations/[id]、POST /api/admin/chat/conversations/[id]/read。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 调用方/接线点：真实后台read handlers→requireAdmin(ADMIN/SALES)→inbox服务
未登录/EDITOR/撤权账号/访客直接读取不返回正文
当前角色每次重验、不会凭隐藏按钮放行（[[E-19]]、[[E-32]]、[[E-78]]）。2) 列表快照按updatedAt/id游标、正文seq分页max100，插页消息完整恰一次
本人read MAX不影响另一运营游标，未展示的新seq仍未读
真实queued/sending/sent/failed/unknown/disabled通知独立返回，不改received（[[E-34]]、[[E-35]]、[[E-79]]）。3) GET/read/通知不延长90d，cookie失效仅访客401，ADMIN/SALES仍读期内咨询
通知失败不改变收件箱可处理状态（[[E-41]]、[[E-86]]、[[E-89]]）。

## 必须处理的边界

- [[E-19]]　在线聊天实现路线
    - 触发：访客猜测其他会话标识或非授权后台账号访问收件箱
    - 期望：拒绝读取和回复；访客只能使用自己的不可猜会话凭据访问本人会话。
- [[E-32]]　C-01 人工聊天收件与回复入口
    - 触发：未登录、EDITOR、已被撤销权限的账号或访客猜测他人会话标识
    - 期望：直接请求读取/回复接口分别验未登录、EDITOR、撤权账号、他人访客凭据均无内容且无写入；ADMIN/SALES 仅按当前权限返回；不以隐藏按钮作为权限证据。
- [[E-34]]　C-01 人工聊天收件与回复入口
    - 触发：刷新收件箱或翻页时又收到新消息
    - 期望：补入已定义 seq 游标与已读 MAX 规则：在分页间插入消息，补齐范围内消息 ID 恰一次；已读只推进到用户实际确认的 seq，新到且 seq 更大的消息仍未读。
- [[E-35]]　C-01 人工聊天收件与回复入口
    - 触发：邮件提醒失败或未接通
    - 期望：将“真实通知状态”落到已定义 queued/sending/sent/failed 或其现有 DTO 映射，保存消息后的通知失败只改变该通知状态，不改变消息 received 或 inbox 可处理状态；未接通不得显示已发送。
- [[E-41]]　C-02 离线留言与发送失败恢复
    - 触发：留言已保存但客服回信或通知发送失败
    - 期望：保留已接收结果及收件箱待处理状态，单独呈现真实发送失败，不假装已联系到访客。
- [[E-78]]　人工聊天同步机制
    - 触发：访客会话到期/撤销，或运营角色从 ADMIN/SALES 变为无聊天权限
    - 期望：下一次轮询和发送均做服务端鉴权并停止返回会话内容；修改 threadId、seq 或邮箱不能读取其他咨询。
- [[E-79]]　人工聊天同步机制
    - 触发：网络中断后恢复或运营收件箱尚有很多未读
    - 期望：把“有界页”引用到既定分页上限并验每次请求不越界、seq 连续补齐；轮询只更新已确认收件游标，不推进用户已读位置，不创建客服在线或已读承诺。
- [[E-86]]　聊天凭据及数据保留期限
    - 触发：隐藏标签页仍有轮询，或仅刷新访问但没有成功收发咨询消息
    - 期望：这些行为不推迟消息/邮箱的 90 天保留截止；咨询活动以成功保存的访客消息或人工回复为准，不把通知重试、投递回执或读状态更新当作新咨询。
- [[E-89]]　聊天凭据及数据保留期限
    - 触发：聊天 cookie 失效但消息尚未到 90 天
    - 期望：访客历史访问立即受阻，运营仍依现有 ADMIN/SALES 权限处理保留中的咨询；不连带改变既有询盘 730 天、分析 30 天/13 个月或备份策略。
