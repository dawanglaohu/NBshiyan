## 必须处理的边界

- [[E-55]]　今日统计的站点时区与历史重算
    - 触发：浏览器或操作系统时区不同的两名运营查看同一日
    - 期望：使用同一站点时区与同一日区间，数值口径不因查看者位置改变，图表及导出标出站点时区。
- [[E-58]]　今日统计的站点时区与历史重算
    - 触发：ADMIN 修改有效时区
    - 期望：保留 UTC 事件时间，标记重算状态，只按仍保留的事件重聚合；已超出 30 天原始保留期的旧聚合保留原时区标签或明确不可重算，不能静默拼成统一口径趋势。
- [[E-61]]　运维指标扩展及角色权限
    - 触发：本轮验收今日授权访客、PV、产品归因与 3D 查看/加载指标
    - 期望：列出一轮真实产品动作证据：同意→实际页面/产品访问→实际 GLB start/terminal→真实五分钟作业提交→看板读取真实日/产品聚合，逐项核今日授权浏览器、PV、归因和3D指标。核心来源不得以未接入或固定值交差。
- [[E-63]]　运维指标扩展及角色权限
    - 触发：3D 加载有成功、失败、超时或没有样本
    - 期望：引用09节既定口径：分母为获同意后真实 model_view_start；同 viewId 最多一个 success/failure 终态，超时记 failure；终态 durationMs 的有效样本算平均耗时并带 samples，无样本为 null，零成功且有样本才为0%，拒绝分析样本不补分母。
- [[E-66]]　运维指标扩展及角色权限
    - 触发：SALES、EDITOR 或未登录用户直接访问运维接口或导出地址
    - 期望：按09/10节来源矩阵直接测：ADMIN全来源、SALES受既有 scope 的业务聚合、EDITOR公开流量/产品/3D；直接请求系统敏感来源403，混合来源响应在查询前裁剪且不含被隐藏计数。

## 实施沉淀

<!-- notes:begin -->
- 成功率来自同一批可配对的授权 start 与 success。只有同时选中两项来源时才返回带 coverage 的读数，分母为零时 value 为 null。耗时以有效终态样本加权，loadDurationSamples 单独返回。[[E-61]]、[[E-63]]
- 三个合法角色都能读取适用于所选 revision 的 recomputableFrom。仅当当前 revision 有可消费的待办时才返回读时的完整保留起点。null 表示本次查询没有可用起点，超期历史保留旧时区标签。缺少历史日行时从时区变更审计解析原标签。[[E-55]]、[[E-58]]
- HTTP 成功响应始终输出 modelSuccessRate 与 recomputableFrom。共享 schema 仍接受只含 sources 的旧 DTO。
- 查询前按角色筛选来源，显式请求全部越权时返回 403。已获准但尚无适配器的非核心来源返回 not_connected。真实签名配置或聚合作业断开时核心来源也返回 not_connected。[[E-66]]
- 旧表切换日需要可信的部署元数据。生产缺少该日期时传 null，有可信日期才参与跨阶段合计。用户级限流为每分钟 30 次，限流存储故障时拒绝请求，最终 HTTP 状态由 apiCounter 记账。
<!-- notes:end -->
