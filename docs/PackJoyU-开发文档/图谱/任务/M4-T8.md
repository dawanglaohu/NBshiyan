# M4-T8　建立主动联系才签发的必要cookie

- 所属模块：[[M4]]　第一方人工咨询：负责访客必要会话、人工消息与离线留言、ADMIN/SALES 收件箱和回复、未读、失败草稿与幂等重试，并保存真实收件和通知结果。
- 前置依赖：[[M3-T14]]、[[M1-T2]]
- 完成后解锁：[[M4-T1]]、[[M4-T2]]

## 输入 / 产出

- **输入**：共享HTTP/config和ChatSessionDTO；09/10必要会话/同源/期限。
- **产出**：ChatVisitorSession；POST /api/chat/session及cookie校验/有限touch。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 调用方/接线点：真实POST /api/chat/session→visitor-session
主动联系才创建随机256bit token/hash库记录，Secure/HttpOnly/SameSite=Lax/Path=/api/chat、无Domain/PII
缺/拒分析不阻止，GET普通网页不签聊天cookie（[[E-40]]）。2) 7d闲置/首次30d绝对、等号/撤销即拒，先验有效再touch
有效cookie可复用，无cookie结果未知不自动循环创建，相同email不恢复旧session
精确Origin和10次/10min cookie、20次/10min IP-HMAC限流生效（[[E-85]]）。

## 必须处理的边界

- [[E-40]]　C-02 离线留言与发送失败恢复
    - 触发：访客拒绝分析但主动打开第一方人工聊天
    - 期望：允许完成必要咨询，不创建分析标识或加载第三方聊天脚本，聊天必要会话与分析同意分开处理。
- [[E-85]]　聊天凭据及数据保留期限
    - 触发：cookie 闲置达到 7 天、签发达到 30 天绝对上限或被撤销
    - 期望：服务端拒绝该凭据访问旧会话，浏览器可建立新咨询；仅填写相同邮箱不能找回旧会话，cookie 与其前端副本均不存 PII。
