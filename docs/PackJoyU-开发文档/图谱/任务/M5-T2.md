## 实施沉淀

<!-- notes:begin -->
重复 true 若把 `Max-Age` 重新写成一年，浏览器保存的到期日会晚于签名里的原期限。签名到期用 `now >= expiresAt` 拒绝，相等不能再当成有效。

删除头必须同时带 `Max-Age=0` 和过去的 `Expires`，并且 `Path`、`SameSite`、`Secure` 与签发时相同。只写数值 0 的 `Max-Age` 时，合并后的删除不会生效。`Path` 是 `/api/analytics`，以后的事件路径也带得上这张 cookie。

没有吊销名单。`false` 只让浏览器丢掉 cookie。客户端把旧值再送回来，到期前验签仍然通过。停采不能靠这次响应变成服务端黑名单。

根密钥缺失或不足 32 字节时没有开发回退。true 返回 503 且不写 cookie，false 仍然清除。轮换 `PRIVACY_HASH_SECRET` 会使已签发的分析 cookie 全部失效，并同时改变 browserHash 和既有邮箱哈希，重叠期内同一浏览器会被算成两段访问。

限流键是 HMAC，不保存原始 IP 或 cookie 原文。已出示的一张长度在 1 到 256 的 cookie 先走自己的桶；超长或多张同名 cookie 不进这个桶。首次同意没有 cookie，签发只受 IP 桶限制。存储失败时拒绝，不改用放行。

成功 JSON 不包含 browserId、browserHash、请求正文、邮箱或 IP。browserId 只在 HttpOnly cookie 里。计数 SQL 只写路由、日期和次数。

`composition.ts` 只在原有 import 之后追加同意服务的 import，并在文件末尾追加组装函数。`src/lib/contracts/analytics.ts` 没有改。
<!-- notes:end -->
