# M3-T10　接通首次绑定表单与一次展示材料

- 所属模块：[[M3]]　后台访问与账号：负责统一后台登录页和后台公共外壳、个人设置、设备会话、验证器绑定与登录方式切换、会话撤销及独立受限恢复；消费 M1 的视觉 token。
- 前置依赖：[[M3-T6]]、[[M3-T2]]
- 完成后解锁：[[M7-T2]]

## 输入 / 产出

- **输入**：M3-T2现有enroll安全后端、M3-T6登录页、M1唯一token。
- **产出**：/admin-enroll表单与登录页首次绑定入口、有效token内存导入/清URL。

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 入口：/admin-login的First authenticator setup（login-enroll）→/admin-enroll
数据源POST /api/auth-admin/enroll、POST /api/auth-admin/enroll/confirm
真实既有token/email/password表单→URI→下一未用新码确认→恢复码一次显示
未确认前无密码开关仍false，绑定错误/过期/重放不变更（[[E-05]]、[[E-08]]）。2) token/URI/码仅内存，历史fragment读入立即清URL，pagehide清秘密
已确认码不再提交登录，回login用下一步新码完成真实登录
无有效token仅输入email不得绑定（[[E-10]]）。 按11节唯一minimalist-flat，在实际服务1920×1080、1440×900、390×844记录GIF与computed style：2px黑边、0圆角、无阴影、强调色#b45700
后台逐页以work/form/card、density7/gutter16/gap16/pad16运行D1–D6和overflow探针。label与键盘焦点可达，触屏控件点击框至少44px。

## 必须处理的边界

- [[E-05]]　C-03 验证器绑定与无密码默认开关
    - 触发：账号尚未绑定验证器
    - 期望：继续使用现有可用登录方式并进入绑定流程；只有正确验证新验证器后才能启用无密码默认登录，不批量强开。
- [[E-08]]　C-03 验证器绑定与无密码默认开关
    - 触发：绑定码错误、已过期、重复提交或并发切换
    - 期望：把四种触发分别测试，并在最终事务复核待绑定记录、有效期和当前凭证版本；错误/过期/重放不提交，两个并发切换最多一个成功，失败后查询仍存在至少一种已验证登录方式。沿09节规则，不另造登录方式。
- [[E-10]]　C-04 验证器丢失与单管理员恢复
    - 触发：正常登录
    - 期望：不显示为必填恢复码，单独“无法使用验证器”进入恢复流程；仅填写账号或邮箱不能获得重置权限。
