# M6-T3　登记存储备份报告与运维采样

- 所属模块：[[M6]]　业务与运维看板：负责按角色查询并解释统计结果，读取询盘、聊天、接口错误、邮件、存储和备份的真实来源，区分数据时间、零值、无数据、未接入、失败和旧值。
- 前置依赖：[[M6-T6]]、[[M5-T1]]、[[M5-T8]]
- 完成后解锁：[[M6-T7]]

## 输入 / 产出

- **输入**：job-foundation、受控服务器脚本、既有备份元数据、10报告契约
- **产出**：ops-sources；ops-sample、POST /api/internal/ops-report与只读报告脚本

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 受控deploy脚本→真实POST /api/internal/ops-report，Bearer与白名单严格
仅空间计数/备份完成验证元数据，拒任意路径和内容
同source+measuredAt同载荷幂等、异载荷409、旧时间不覆盖新值
无验证来源not_connected
SALES/EDITOR直接GET stats的STORAGE/BACKUP来源403且无计数，后台session不能替代report Bearer（[[E-65]]、[[E-66]]）。2) ops-sample在registry、composition、cron实际注册每15分钟，重启后按计划运行
真实measuredAt/lastSucceededAt读取到stats，停止报告显示原时间/旧值，未做恢复验证不能标可恢复
辅助源异常不阻断核心（[[E-67]]）。

## 必须处理的边界

- [[E-65]]　运维指标扩展及角色权限
    - 触发：存储健康或备份没有可验证来源
    - 期望：仅显示未接入及来源状态；接通后显示真实检查/完成时间，不以普通文件上传、页面查询成功或计划时间假装备份成功，也不暗中新增备份平台或付费服务。
- [[E-66]]　运维指标扩展及角色权限
    - 触发：SALES、EDITOR 或未登录用户直接访问运维接口或导出地址
    - 期望：按09/10节来源矩阵直接测：ADMIN全来源、SALES受既有 scope 的业务聚合、EDITOR公开流量/产品/3D；直接请求系统敏感来源403，混合来源响应在查询前裁剪且不含被隐藏计数。
- [[E-67]]　运维指标扩展及角色权限
    - 触发：任一附加来源中断或无数据
    - 期望：该卡独立显示错误、旧值、未知或未接入；其他真实指标仍可查询，避免单个辅助来源拖垮整张看板。
