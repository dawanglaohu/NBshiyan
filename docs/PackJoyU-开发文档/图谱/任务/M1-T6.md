# M1-T6　逐帧替换GIF品牌并校验发布媒体集合

- 所属模块：[[M1]]　品牌与公共体验：负责现用 PackJoyU 字标、己方可证公司内容、JPG/GIF 发布副本、首页媒体和前台公共页面，并作为全站前后台视觉 token 的唯一归属；不承担后台权限或后台外壳。
- 前置依赖：[[M1-T3]]
- 完成后解锁：[[M1-T4]]

## 输入 / 产出

- **输入**：原361帧GIF、brand-static-media、现用字标与原始时间轴
- **产出**：brand-media；换标GIF、等尺寸暂停帧、逐帧品牌/时序报告与可发布集合

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 保留原JPG/GIF哈希，逐帧列出361帧中旧品牌出现、透视变化、转场及遮挡恢复位置，全部以PackJoyU完整覆盖
同时复核T3选定静态发布图的品牌位置，首尾帧与全部列出位置无旧标或漏标（[[E-26]]）。2) 用原时间轴对照每帧呈现时刻/顺序和30.08秒循环总长，全部相同
叠加对照无替换新增错位或抖动
任一失败则该副本标未完成且排除发布，原件保留回退（[[E-30]]）。3) 输出可解码GIF、同尺寸暂停静帧与哈希
GPT Dot制作证据或逐项尚未执行状态按T3的真实工具可达结果登记，不虚报完成。

## 必须处理的边界

- [[E-26]]　自己的Logo与参考PDF事实边界
    - 触发：JPG 或 GIF 任一帧、任一透视平面存在旧品牌
    - 期望：保留原件，对发布副本逐帧跟踪清理并以 PackJoyU 标识替换，抽帧核查首尾帧、转场和遮挡恢复处，不只改封面或模糊旧 logo。
- [[E-30]]　自己的Logo与参考PDF事实边界
    - 触发：替换后的 GIF 不能保持原时序、画面稳定或正确品牌覆盖
    - 期望：沿原 GIF 时间轴逐帧对照发布副本：帧呈现时刻、顺序与循环总时长保持不变；每次旧品牌出现、透视变化、转场及遮挡后再现均由 PackJoyU 完整覆盖，不出现替换新增的错位、漏标或抖动。任一项失败则继续修复该发布副本，将文件标为未完成且不纳入发布成品；原始 JPG/GIF 始终保留用于回退。
