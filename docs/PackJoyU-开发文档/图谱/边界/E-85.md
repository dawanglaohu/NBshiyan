# E-85　聊天凭据及数据保留期限

| | |
|---|---|
| 触发条件 | cookie 闲置达到 7 天、签发达到 30 天绝对上限或被撤销 |
| 期望行为 | 服务端拒绝该凭据访问旧会话，浏览器可建立新咨询；仅填写相同邮箱不能找回旧会话，cookie 与其前端副本均不存 PII。 |
