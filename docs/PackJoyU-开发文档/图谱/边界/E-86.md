# E-86　聊天凭据及数据保留期限

| | |
|---|---|
| 触发条件 | 隐藏标签页仍有轮询，或仅刷新访问但没有成功收发咨询消息 |
| 期望行为 | 这些行为不推迟消息/邮箱的 90 天保留截止；咨询活动以成功保存的访客消息或人工回复为准，不把通知重试、投递回执或读状态更新当作新咨询。 |
| 归属模块 | [[M4]] |
