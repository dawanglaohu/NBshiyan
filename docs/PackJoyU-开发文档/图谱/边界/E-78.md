# E-78　人工聊天同步机制

| | |
|---|---|
| 触发条件 | 访客会话到期/撤销，或运营角色从 ADMIN/SALES 变为无聊天权限 |
| 期望行为 | 下一次轮询和发送均做服务端鉴权并停止返回会话内容；修改 threadId、seq 或邮箱不能读取其他咨询。 |
| 归属模块 | [[M4]] |
