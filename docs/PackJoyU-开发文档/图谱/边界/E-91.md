# E-91　聊天通知持久队列

| | |
|---|---|
| 触发条件 | 多个 cron worker 并发领取，或领取者崩溃直到租约到期 |
| 期望行为 | 原子领取并携带租约/代次提交状态；过期工作可重新领取，旧 worker 不能覆盖新租约的处理结果，通知失败不得撤回已经成功保存的聊天消息。 |
| 归属模块 | [[M4]] |

## 被这些任务兜底
