# E-69　设备会话与Auth.js期限接合

| | |
|---|---|
| 触发条件 | 普通会话距上次有效活动达到 2 小时，或自创建达到 12 小时绝对截止；记住设备达到 7 天闲置或首次签发起 30 天绝对期限 |
| 期望行为 | 服务端在写入 lastActivityAt 之前拒绝授权（到期时刻的等号即拒绝），并清理可写响应中的 cookie；JWT 和 Set-Cookie 到期时间均不得越过该设备实际允许期限，刷新不能延长绝对上限。 |
| 归属模块 | [[M3]] |

- [[M3-T15]]　通过真实活动写回会话期限并验证四条Auth.js路径
- [[M7-T2]]　终验真实会话跨路径持久与撤销
