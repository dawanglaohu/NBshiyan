# E-77　人工聊天同步机制

| | |
|---|---|
| 触发条件 | 多个标签页、重试、响应乱序或跨分页期间又插入新消息 |
| 期望行为 | 以服务端稳定 seq 和消息标识合并去重，游标只推进到已完整接收的范围；后返回的旧响应不能倒退游标、覆盖新回复或把漏页消息跳过。 |
| 归属模块 | [[M4]] |

- [[M4-T9]]　集成聊天轮询、断网重试与失权停止
