# E-98　页面滚动与缩放

| | |
|---|---|
| 触发条件 | 指针在模型视口、工具条、正文或另一模型上使用普通滚轮、触控板或 Ctrl/Cmd+wheel |
| 期望行为 | 普通滚轮和触控板始终正常滚页；Ctrl/Cmd+wheel仅在真实焦点归属某模型视口/命名工具条且指针命中同一模型视口/工具条时改变该相机，明确缩放按钮仍可点击。焦点与指针分属不同模型，或指针落在标题/说明/规格/链接等非控制区时，所有模型相机不变且保留浏览器行为；退出后释放所有滚轮拦截，不凭缓存焦点再次接管。 |
| 归属模块 | [[M2]] |
