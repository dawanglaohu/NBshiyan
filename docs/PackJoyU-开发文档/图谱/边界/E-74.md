# E-74　敏感设置的新鲜本人验证

| | |
|---|---|
| 触发条件 | 授权签发后超过 5 分钟、设备撤销、密码/验证器变更或账号权限失效 |
| 期望行为 | 旧授权立即无效；授权的新鲜验证不得跨设备移用，也不能延长原设备会话期限。 |
| 归属模块 | [[M3]] |

## 被这些任务兜底

- [[M3-T12]]　接通个人安全页与共享新鲜验证对话框
- [[M3-T13]]　接通退出全部设备确认与结果核实
- [[M3-T16]]　原子切换本人登录方式与密码
- [[M3-T17]]　提供本人设备列表及目标撤销API
- [[M3-T3]]　签发一次性新鲜本人授权
- [[M7-T6]]　终验新鲜本人授权与忘密码隔离
