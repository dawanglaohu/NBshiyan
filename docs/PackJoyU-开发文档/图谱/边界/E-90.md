# E-90　聊天通知持久队列

| | |
|---|---|
| 触发条件 | 保存消息后进程立即中断，或客户端因超时重发同一消息 |
| 期望行为 | 在同一数据库事务内保存消息及 messageId 唯一的出箱记录；已提交消息可在重启后继续通知，消息幂等命中不能新增第二条通知。 |
| 归属模块 | [[M4]] |
