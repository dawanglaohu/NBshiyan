# E-102　触屏手势

| | |
|---|---|
| 触发条件 | 手指在模型视口拖动/双指缩放或在卡片文字区域滑动 |
| 期望行为 | 以单指模型拖动、双指缩放、文字区滑动分别验证：仅模型操作区接管拖动，缩放不能越该产品已定义 min/max，文字/页面滚动可用；测量每个控件点击目标≥44 CSS px，任一手势不触发询盘提交。 |
| 归属模块 | [[M2]] |
