## 2. R5 实现事实

### 2.1 阶段分类器

`src/lib/server/analytics/aggregate.ts:145-157`：

```ts
function asPreflightStageError(error: unknown): unknown {
  if (error instanceof AggregateGuardFailure) return error;          // 不重复包装
  if (error instanceof AggregateDeadlineExceeded) return error;      // deadline 原分类
  if (error instanceof AggregateVersionConflict) return error;       // 版本冲突原分类
  if (isBudgetFailure(error)) return error;                          // P2028/57014/55P03
  if (isWriteConflict(error)) return new AggregateVersionConflict('write_conflict'); // 40001/40P01/P2034
  return new AggregateGuardFailure(error);                           // 其余未知
}
```

与 R4 的 `assertCurrentTimezoneRevision` 内部 catch 语义一致；两个函数对同一批错误给出同一分类，不会出现“守卫内标了、外层又包一层”。

### 2.2 `aggregateOneDayInSnapshot`（preflight 单日）
