## 发现与修复

- **B1 [S1] 涉及 M5-T12、M5-T4、M5-T8、M5-T10（跨批）**：管理员改站点时区后，`analytics-aggregate` 消费并删除 `analytics.recompute`，但 `daily.baseDates` 仅含最近 48h+今日，导致 30 天原始窗内其余约 27 个可重算日在新 `timezoneRevision` 下被 `writeDailyMetadataPhase` 误写为 `not_backfilled` 且无 `AnalyticsDaily` 行。根因在 `src/lib/server/analytics/aggregate.ts:547-565,604-625` 未在 `rebuildFrom !== undefined` 时将 `plan.siteDates` 并入 `dailyBaseDates`。修复提交：`6175c5f0`（补真 PG 回归 `tests/jobs-runtime.http.test.ts`）。
- **B2 [S2] 涉及 M5-T12**：`today` 在 `daily.baseDates` 中提交过一次后，再次遇到 `guard`/`budget` 中止时，`readDayStatesInDomain(..., floor, today)` 严格排除 `today` 导致 `planExpected.updatedAt=null`，回滚后 `writeDailyGap` 走 `ON CONFLICT DO NOTHING` 返回 `cas_failed` 而丢弃 `today` 缺口。根因在 `src/lib/server/analytics/aggregate.ts:1053-1055,1628-1630`。修复提交：`6175c5f0`（补真 PG 回归 `tests/analytics-daily.db.test.ts`）。
- **B3 [S2] 涉及 M5-T12**：`AnalyticsAggregateDayState` 保留候选与删除的 SQL 预筛 `WHERE localDate < shiftCalendarMonths(currentDate, -13)` 挡掉了精确 13 个月等号到期日、月末夹取到期日（如 `2025-01-31` 于 `2026-02-28` 到期）及更东时区旧 revision 的已到期 state 行。根因在 `src/lib/server/analytics/retention-plan.ts:476-479`。修复提交：`dddb8392`（将预筛上界扩宽 +6 天、仍由行级 `dailyExpiresAt <= now` 精确判定，补真 PG 回归 `tests/analytics-retention.db.test.ts`）。
- **B4 [S2] 涉及 M5-T10**：`/admin/settings?section=analytics` 首次 `GET` 失败后点击「重试」，成功时输入框保持空白 `""` 且误报「你的输入保留」，失败时错误被吞；首次 `GET` 返回 401（`action='login'`）时页面永久停在「加载中…」。根因在 `src/components/admin/stats/AnalyticsSettingsContainer.tsx:72-87,107-118`。修复提交：`731eb20e`（抽取 `src/lib/admin/analytics-settings-state.ts` 区分初始重试与 409 重读并显式呈现 401，补单测 `tests/analytics-settings-ui.test.ts` 与真浏览器回归验证）。
