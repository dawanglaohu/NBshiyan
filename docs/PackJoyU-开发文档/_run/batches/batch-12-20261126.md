## 发现与修复

B1 [S2] M4-T5 与 M4-T2、M4-T11 的分页接缝。服务端还有第 51 页时，旧客户端把已验证的 50 页作为一次失败丢弃，下次仍从旧游标读取。默认每页 50 条会在超过 2,500 条待同步消息时触发。修复 `b4a5fdff` 保留单次请求上限，在上限返回前缀和实际接收游标。回归以每页一条验证 51 个连续请求、作者映射及第二次刷新。见 `src/lib/client/chat.ts:405`、`tests/chat-refresh-pagination.test.ts:26`。
