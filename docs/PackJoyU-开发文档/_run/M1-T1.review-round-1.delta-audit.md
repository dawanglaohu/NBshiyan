# M1-T1 局部补丁变化审计

补丁：m1-t1-review-standalone-config；只读解析真实补丁 before/after，并重算全部84项契约哈希。未调用 verify，未修改仓库或 GitHub。

## 结论

- 唯一源变化：`_run/task-contracts.json → tasks.M1-T1.supportPaths` 从 `[]` 增为 `["playwright.config.ts"]`。对补丁保存的27份源快照逐份核对当前源文件，只有此处源变更，当前均匹配。
- M1-T1 的4个递归变化：`context.definition.supportPaths`、`context.effectivePaths`、顶层 `effectivePaths`、`hash`。前三项都只新增 `playwright.config.ts`。验收、边界、原任务前置和requires未变。
- 其余83项每项只有顶层 `hash` 不同，完整 `context` 逐项递归相等。各任务自己的验收、边界、路径、前置/requires、输出、阶段、架构、视觉、共享章节及接线没有实际变化。
- 83项全部以M1-T1为真实祖先；其祖先context base hash仅M1-T1改变。全部84项before/after哈希按现有生成器公式重算并逐字匹配。传播原因是`handoff_contract.py:328–333`把真实祖先的base hash纳入契约，**不是**把全源task-contracts文件指纹直接塞进每个任务。全源指纹只另行改变sourceVersion。
- 83项旧task-reviews记录均为pass，且contractHash逐项匹配补丁before；可复用其原契约语义证据，再追加本轮精确delta证据。
