## 确定遗漏

### RQ-01 / P1：原有后台页面的视觉迁移没有完整任务归属

用户原话第 6 点要求“管理后台更换登录页 ui，选一个风格同步更换管理后台风格”（`_run/context.md:10`）。目标章也承诺后台登录与内部页面采用一致视觉规范（`00-概览/01-概述与目标.md:16`）。

但当前交付范围被收窄为 16 个路由模式：`02-设计/11-UI.md:5`。其页面表只包含新登录/账号/设备/聊天/看板，以及设置和用户恢复按钮；没有既有询盘列表与详情、模型列表/上传、规格列表/编辑、未分配邮件等页面。`02-设计/07-前端架构.md:206` 又明确既有未触达路由仅引用 sourceMap。

唯一原后台视觉相关任务 M3-T7（`04-执行/19-模块任务拆分.md:33`）验收只覆盖外壳、角色导航、活动和退出。实际派发 M3-T7 的 implementation 同样只交“后台外壳”；有效范围包含 `src/app/admin/admin.css`，不含 `src/app/admin/mail.css`、`src/components/admin/specs/specs.css`、`src/components/admin/models/models.css`、`src/components/admin/settings/settings.css`、`src/components/admin/settings/about-images.css` 或既有页面内联样式。`presentation.json` 全部 78 个 taskPaths 没有 mail.css，也无 InquiryDetail/匿名化标签的视觉任务归属。

这是实际缺口而非纯粹补测建议：

- `src/app/admin/mail.css:2` 定义独立旧色板；`:5`、`:15`、`:18`、`:21` 等保留 8/12/999px 圆角及 1px 边界。这些不因修改公共 token 自然变成 11 节要求的 2px/0 圆角风格。
- `src/components/admin/InquiryDetail.tsx:176` 有内联 conic-gradient；`src/components/admin/anonymized.tsx:13` 与 `:79` 有内联 4/999px 圆角和 1px 边界。只动 admin.css 无法保证这些内联旧值消失。
- `src/components/admin/specs/specs.css:10-11` 自带旧成功/错误背景与圆角；模型和设置也有各自样式文件。

最小修补：在现有 M3 视觉范围追加有限任务，明确“仅迁移原有后台视觉，保留原业务/权限/发布开关”。给原有已上线页面列清单（含条件开启的邮件页面），把上面独立 CSS 与少量内联视觉路径列入 taskPaths/supportPaths；逐页定义 work/form 类型及真实入口、原数据源、锁定 minimalist-flat 的 computed style、D1–D6 与 1920/1440/390 验收。最终交付任务依赖这些视觉任务。不要把全部工作塞进已估 1 天的 M3-T7，也不要因此扩展原邮件业务或新建后台模块。源、契约、任务笔记、派发和排程同步重建后复核。
