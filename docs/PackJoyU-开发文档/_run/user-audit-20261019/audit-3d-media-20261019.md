### B. 3D 统计 start 触发条件存在一处矛盾（协议精修）

- `12-UX.md:68` 写“可见或主动操作触发真实模型加载与 viewId”，`09:68` 写每次真实模型发起生成一次 viewId。源码 `ProductGallery.tsx:73–103、159–164` 也会在 armed 且 visible 后加载模型。

### C. 产品目录数据来源的验收强迫了不存在的浏览器 GET（事实精修）

- 当前 `src/app/[locale]/products/page.tsx:9–13、34` 服务端调用 `loadCatalog(listPublishedModels, ...)`，60 秒 ISR；`src/app/api/models/route.ts:10–12` 是同一读取函数的兼容 HTTP 入口。产品页浏览器无需发 GET `/api/models` 才能取得目录。
