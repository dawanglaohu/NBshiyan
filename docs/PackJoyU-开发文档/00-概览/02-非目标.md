# 非目标

本轮围绕产品展示、询盘、人工联系、后台登录和运营可见性展开。范围以用户原话及 `_run/decisions.md` 为准；下面的边界用于避免实施时扩大产品或误用恢复资料。

- 不增加商城结算、付款、库存、物流订单或企业生产管理。Gift Cards 是印刷贺卡，不是储值卡。
- 不重写整套技术栈，不拆独立前后端项目，不因界面改版迁移数据库或托管商。S3 才确定视觉规格，本 S1 不生成产品页面、视觉变体或需要用户回来看图的确认闸门。
- 不将旧恢复工作区整体当作当前实现。已合并历史、走查脚本、本机 Playwright 配置、生产配置、密钥、数据库、原始对话和备份都不进入业务 PR。保存翻译草稿不等于发布新语言；本轮基线仍为 en/ru。
- 不自动合并恢复 PR、部署生产、替换实际服务器配置或迁移 Sanity webhook。恢复草稿的审核与上线各有独立证据，草稿上传本身不代表通过验收。
- 不删除账号恢复能力，不让未绑定账号直接进入无密码模式。也不把账号标识与 TOTP 码宣传为两个独立认证因素；界面可以沿用用户熟悉的“2FA”，但须说明实际登录方式。
- 不接入 AI 自动客服、语音、坐席绩效、全功能工单中心或额外第三方客服脚本。Chatwoot 和 LiveHelperChat 已考虑过，本轮因独立资源与维护面不采用，选择现有栈内的最小人工会话闭环；理由见 05 节。
- 不强制首屏同时下载所有视频和动图，不自动带声播放，不用媒体遮挡产品与询盘操作。JPG/GIF 是等距场景插画，不能当成 PackJoyU 真实厂区照片。
- 不把 YUHAO PDF 中的认证、历史、产能、人数、设备、面积、客户品牌、地图、照片、地址、MOQ 或交期改名作为 PackJoyU 事实。自有工厂身份已在此前项目沟通中确认，具体对外声明仍需自己的依据。
- 不新建全功能监控平台，不承诺未经评估的容量、SLA、收入或生产指标。没有真实来源的辅助指标显示未接入；这项边界不豁免核心访客与 3D 统计。
- 不用指纹、跨站身份或原始 IP 追踪唯一真人，不以拒绝分析为由禁用产品、3D 或必要人工咨询，不将分析事件发送给新增第三方平台。
- 不自动购买服务、扩容或订阅，不作新的对外业务承诺，不不可逆删除现有备份与业务数据。

产品顾问提出的 C-01 至 C-06 全部纳入本轮，没有被删除的能力候选。C-06 的第二意见认为“非必要”，代理用户仍基于看板可用性采纳；C-02 等低置信项保留原始概率与边界，不用多数意见冒充用户原话。没有被采纳的是错误或过宽的实现方案，而非用户要求的联系和看板闭环。
