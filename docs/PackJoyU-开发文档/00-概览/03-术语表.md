# 术语表

表中“规划能力”表示本轮尚未实施，不能据此认定代码已有对应功能。正式实体、路由与模块命名由 S2 契约约束。

| 术语 | 含义 | 代码中对应 |
|---|---|---|
| PackJoyU / 保乐优 | 当前项目自己的包装展示与询盘品牌 | `SiteHeader.tsx` 的 PackJoyU 字标；`src/app/icon.svg` |
| 产品卡片 | 列表里承载产品主体、名称与操作的单元 | `src/components` 中现有产品展示组件 |
| 3D 直接操控 | 鼠标或触控直接改变模型视角，同时能退出、复位 | 现有 React Three Fiber / Drei / Three.js 展示链路；本轮规划改进 |
| 询盘 | 访客咨询包装需求，由运营后续联系 | Prisma `Inquiry`、`InquiryMessage`、`InquiryItem` |
| Gift Cards | 印刷贺卡 | 现有 gift-cards 品类与英俄文案；不是储值卡 |
| ADMIN / SALES / EDITOR | 管理员、销售、内容编辑的现有角色 | `prisma/schema.prisma`、后台 `guard` |
| 验证器码 / TOTP | 验证器生成的短时动态码 | `otplib`、`src/lib/server/admin/login.ts` |
| 无密码验证器登录 | 本人验证启用后，账号标识加验证器码登录 | 规划能力；现有 `src/auth.ts` 仍要求密码 |
| 恢复码 | 验证器不可用时的一次性账号恢复凭据 | 现有 Argon2 哈希校验；本轮规划独立恢复入口 |
| 绑定链接 | 账号验证器首次或重置绑定的一次性入口，令牌在 fragment 中 | `/admin-enroll#t=…`、`EnrollWizard`、`EnrollLinkPanel` |
| 会话持久化 | 浏览器重新打开后仍按期限和撤销状态维持登录 | Auth.js JWT Cookie、`sessionVersion`；本轮规划设备会话策略 |
| 记住此设备 | 本人选择后采用较长但有闲置与绝对上限的会话 | 决策 1：7 天闲置 / 30 天绝对上限 |
| 授权访客 / UV | 同意分析的匿名浏览器按统计日去重数量 | 规划第一方分析；不等于唯一真人 |
| PV | 符合口径的真实页面访问次数 | 规划页面事件；重复同一事件 ID 不重复计数 |
| 3D 查看发起 / 加载结果 | 打开模型与加载成功、失败分开的事件 | 规划产品分析事件；不由进入产品页推定 |
| 统计日 / IANA 时区 | 按站点时区的本地午夜到次日午夜，左闭右开 | 决策 11；初始 UTC，夏令时交给时区库 |
| 已接收 | 服务端成功持久化消息 | 规划第一方人工聊天；不表示已读或邮件已投递 |
| 人工收件箱 | 授权运营查看与回复访客消息的工作入口 | 规划能力，复用现有账号角色；不能把旧询盘表直接当成已实现聊天 |
| 幂等重试 | 同一操作重复提交仍只产生一次业务结果 | 规划会话消息 ID / 分析事件 ID 去重 |
| Token / 视觉令牌 | 集中定义颜色、文字、间距等视觉取值 | 第11节视觉规格；与登录凭据不同 |
| 草稿 PR | 保存成果供审阅，未表示可合并、上线或数据已导入 | GitHub draft pull request、官方 `gh stack` |
| TypeSafe / Jev | 本次文档流程的第二意见与有限选项校准 | `_run/typesafe_ask.py`、`_run/judgments.jsonl`；本轮不加入产品运行时 |
| 实际授权制作渠道 | 已确认素材先复用；缺项才依已有授权补制作/工程并留证 | Dot只是可选渠道，采用时核实际调用；未用不否定其他真实成果 |
