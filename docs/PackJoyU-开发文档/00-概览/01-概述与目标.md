# 概述与目标

PackJoyU（保乐优）是面向海外客户的包装产品展示与询盘网站。本次升级让访客更直观地看产品、操作 3D、了解公司并联系人工客服，同时让运营人员能稳定登录后台、管理咨询和查看真实访问数据。它沿用现有项目，成果以可审阅的代码、真实浏览器验证和可追溯素材交付。

## 使用者与当前基线

访客通过英语或俄语浏览网站、查看产品并提交咨询。ADMIN 管理账号和全站运维；SALES 处理获授权的咨询与业务统计；EDITOR 管理获授权的内容。角色限制由服务端执行。

本轮源码基线为 main `971b5b46faa0c468fc85372773de612bebd51c3c`。源码已有产品、询盘、3D 展示、后台账号和一次性验证器绑定后端。恢复码在现有后端不是必填，而默认登录页把 email、password、totp、recoveryCode 并排列出，缺正确类型和方式提示；目前仍需密码。Auth.js 的会话端点具备刷新能力，但现有后台未接明确的主动刷新链路；本轮须补齐真实续会话和撤销路径，不能只改两小时参数。后台数据看板是禁用占位，Web Vitals 日志也不能代替访客统计。以上是源码事实，不代表生产已部署到该提交。

## 本轮目标

1. **保存未发布成果。** 对照实时 GitHub、恢复提交和工作区修改，按功能发布独立草稿 PR。已合并的旧分支不重复发布；旧草稿不整体覆盖较新的主线。翻译源资料可保存，但不由此开放新语言、导入内容或部署。
2. **扩大产品表达与 3D 操作空间。** PC 产品卡片让产品主体、名称与关键操作清楚可辨；删减底部重复介绍，为模型让出空间。鼠标直接操作模型时，拖动、页面滚动、自动旋转和卡片点击不得互相争抢，提供明确的开始操作、退出与复位反馈。失败时有可读的图片回退，触屏和键盘也可完成查看与询盘。具体尺寸、控件和交互阈值在 S3 定稿。
3. **重做前台视觉与主页媒体。** 参考用户指定的 EUPRO 网站的信息层级、产品表现和联系入口，设计自己的页面。12.27 秒视频静音行内展示并可暂停；自动播放受限时保留主动播放入口。JPG、GIF 可在同页的不同区域展示，GIF 接近可见时加载，暂停可切换为同尺寸静帧；减少动态效果时优先静态展示。视频海报须与视频内容语义相符，不能把插画当作真实厂区画面。
4. **重做后台登录与后台界面。** 增加个人信息页、记住设备策略和无密码验证器登录开关。本人校验绑定后可将“账号 + 验证器码”设为默认方式，日常无需密码、无需恢复码；未绑定账号不批量强开。普通退出、退出全部设备、改密、重置验证器和禁用账号都要按各自范围撤销会话。后台登录页与内部页面采用一致的视觉规范；具体风格在 S3 以 token 和组件规格交付。
5. **保留独立账号恢复。** 采纳 C-03、C-04，完成绑定、开关切换和丢失验证器后的恢复。恢复会话只能重新绑定，经新码验证后才能取得后台权限；一次性凭据原子核销。无恢复码时须由重新验证的另一管理员授权；单管理员场景使用服务器所有者具有操作系统管理权限的本地审计恢复途径，不允许匿名邮件重置或日常手工改库。
6. **建成业务和运维数据看板。** 采纳 C-05、C-06，核心必须包含真实采集、去重、聚合、查询到页面展示的授权访客、PV、产品归因、3D 查看与加载结果。补充询盘/聊天发起、接口错误、邮件通知失败，以及有真实来源的存储和备份状态。数据卡分别说明统计口径、数据时间和零值、无数据、未接入、查询失败、旧值。不能用演示数字完成验收。
7. **用第一方人工聊天替代原工具。** 采纳 C-01、C-02，在现有 Next.js/PostgreSQL 中提供访客会话、ADMIN/SALES 收件箱、人工回复、未读及离线留言。消息成功保存才显示已接收；通知失败不丢咨询，网络重试不重复收件。访客可主动留邮箱，未发送草稿仅保存在当前标签页内存。必要聊天会话与分析同意分别处理。
8. **重做自己的品牌素材。** 使用现有 PackJoyU 字标。JPG、GIF 的飞艇及建筑墙面旧品牌要在发布副本中跟踪、清理和透视换标，GIF 核查全部 361 帧及完整循环，保留原始文件。参考 PDF 只提供内容组织、产品主题和设计参考；重新制作公司介绍时只使用可核实的己方事实。用户已允许 GPT Dot 在远程电脑使用软件制作；实际调用和制作证据必须留存。

## 统计口径与完成定义

“授权访客”指允许分析后的匿名浏览器，不等于跨设备唯一真人。同浏览器当日去重，页面访问和 3D 发起/成功/失败分开；不保存原始 IP、跨站指纹、邮箱或聊天正文作为分析数据。原始事件保留 30 天、无个人关联标识的聚合保留 13 个月。统计日按站点 IANA 时区，初始 UTC，图表明示；修改时区不假装能重算已过保留期的原始事件。

完成须有对应提交和检查结果、真实服务与浏览器路径、有效权限拒绝和失败恢复证据。未接入的辅助指标可明确展示来源状态；用户点名的访问和 3D 核心指标必须真实接通。素材必须有原件、处理来源和播放检查。本 S1 只冻结需求及选型，尚未实现本轮改版，也未生成任务知识库和离线阅读器。
