## `color-printing` — `/es/products/impresion-de-embalaje` (Impresión de embalaje)

<details id="faq-color-printing-es-1"><summary>¿Qué diferencia hay entre la impresión CMYK y Pantone?</summary>

CMYK crea los colores con cuatro tintas de cuatricromía y es adecuado para fotos y degradados. Las tintas Pantone (directas) vienen premezcladas para colores de marca exactos. Muchos trabajos combinan ambas.

</details>
