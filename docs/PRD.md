# PRD v1.1：PackJoyU 外贸展示站

## 1. 定位
展示产品与公司实力、获取询盘，不做在线交易。目标市场：北美、欧洲、澳洲、俄罗斯。语言：第一期 `en`、`ru`（x-default 为 en），第二期按询盘数据补 de/fr/es。

## 2. 产品范围
瓦楞纸箱、彩盒、礼盒、纸浆模塑、纸杯、派对用品、酒盒、彩色印刷、胶印、环保纸杯、礼品卡、圣诞周边（共 12 类）。

## 3. 第一期功能
- 开屏视频（≈5s，可跳过，仅首次访问，不遮挡 HTML 正文）+ 首页动画
- 3D 展示页：12 个模型同页不分页，共享单个 WebGL 画布（drei View），视口内加载，带尺寸参照物
- 礼盒、酒盒、瓦楞纸箱：开箱 / 折叠展开动画
- 3D 定制器：换色、贴 logo；规则盒型可调尺寸；方案短链接 `/s/<随机id>`（noindex）
- 询价向导、询价清单、样品申请 → 统一询盘接口（多产品、带参数、可信度评分、自动分配）
- 工厂实力：全景、认证墙、产能数据
- 12 个产品落地页、行业方案页、5–10 篇基础文章（Sanity 管理，含各语言 SEO 字段）
- 在线客服 Tawk.to（多语言欢迎语，空闲时加载）、Cookie 同意条、隐私政策
- 真实用户性能监控

## 4. 管理后台 `/admin`
询盘管理与回复、3D 模型上传/压缩/预览/上下架、产品与内容（Sanity）、样品审核、客服与站点设置、角色权限（管理员/业务员/编辑）与操作日志、数据看板。

## 5. 技术栈
Next.js App Router + next-intl；three.js / react-three-fiber；GLB + Draco + gltf-progressive；IndexedDB 缓存；Postgres + Prisma；Auth.js + 2FA；Sanity；Resend；Vercel + Cloudflare（CDN、R2、Turnstile、Access）。

## 6. 验收指标
桌面首屏 < 2s，移动 < 3s；3D 首次可交互 < 3s；单模型 ≤ 1MB（带动画 ≤ 1.5MB）。CI 中 Lighthouse 不达标则构建失败。

## 7. 第二期
AR 预览、AI 包装顾问、其余模型动画、材质近看、尺寸运费计算器、节日专题页、CRM 对接、更多语言。

## 8. 排期
- W1：品牌方向、项目框架、数据库、部署流程、关键词地图
- W2–3：线框图、3D 原型（3 个模型验证性能）、询盘接口与后台询盘页
- W4–5：其余模型、定制器、询价流程、后台模型管理、内容
- W6：联调、性能与安全验收、俄罗斯测速、交付试用

## 9. 已确认决策
- 品牌：方向 C（暖白底 + 珊瑚橙）为主调，礼盒、酒盒分类区借用方向 B（深色 + 烫金），字体 Manrope（拉丁 + 西里尔子集）
- 语言：en、ru；不做从右到左排版
- 后台询盘：可信度 < 40 分归入“待核实”，链接显示为纯文本完整网址，附件服务端扫描后仅可下载
- 模型上传：上传 → 处理中 → 预览确认 → 上架，接口返回逐项检查结果（格式、压缩、轻量版、体积）
- 依赖：大版本升级人工评估，小版本与补丁合并为一个 PR
- 客户 Logo 上传（一期）：前台公开，只收 PNG/JPEG/WebP，≤2MB，按文件头判类型并用 sharp 重新编码；上传返回 1 小时有效的 uploadId，提交询盘时绑定，人机校验只在提交询盘时做一次；按 IP 限流加全站总量上限；文件存私有区域，未绑定的 24 小时删除，已绑定的 30 天删除，只在后台询盘详情经鉴权查看。向导提示“有 PDF/AI 等矢量文件，请在回复询盘邮件时作为附件发来”。矢量格式（PDF/AI/SVG）上传放到二期，需先做安全转换方案。
