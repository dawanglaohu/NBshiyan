前端按下表实现；参数全部来自 design/motion-tokens.css（CSS 自定义属性）。礼盒/酒盒区（主题 B）同一套参数，不另加特效。

硬性规则（SEO / 性能，LCP 与 CLS）

  1. 只动 transform 和 opacity。禁止动画 width/height/top/left/margin/padding，避免布局跳动（CLS）。颜色/阴影过渡只用于 hover 小元素。
  2. 首屏标题和主图一开始就显示，不得从 opacity:0 淡入，也不得等 JS 再显示（否则推迟 LCP）。淡入只用于首屏以下、滚动进入的区块。
  3. 滚动入场区块不得用 display:none、visibility:hidden 或折叠高度；内容默认就在服务端 HTML 中且可见。隐藏初始态只在 JS 给 <html> 加 .reveal-ready 后生效，JS 失败/禁用时内容照常显示，搜索引擎直接可读。
  4. 首屏背景视频：静音、单次播放、带 poster（即首屏主图），视频不是 LCP 元素；尺寸用 aspect-ratio 预留，加载前后不改变布局。CSP 只允许同源媒体。
  5. 动画中不得阻塞交互；同时运行的入场动画 ≤ 4 个；用 IntersectionObserver，不监听 scroll 事件；只在需要时临时加 will-change。
  6. 开启“减少动态效果”（prefers-reduced-motion: reduce）时：无位移、无缩放、无视差、无自动播放/自动旋转；最多保留 120ms 淡入。

实现备注

  • 滚动入场 CSS 见 motion-tokens.css 的 .reveal；IntersectionObserver rootMargin 0px 0px -10% 0px，触发一次后 unobserve。
  • 首屏内（视口高度以内）的 .reveal 元素在首帧直接加 .in，不播放。
  • Save-Data 或 2G 网络：不加载背景视频，3D 不自动旋转。
  • 动画离开状态比进入快（约 0.6×），离开用 ease-in。
