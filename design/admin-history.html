② 字段映射
字段显示说明
type status|assign|reply左侧图标 + 颜色（不只靠颜色，图标形状不同，并有 aria-label）未知 type → 灰色 • 图标，照常显示 summary
summary主文字，原样显示（转义，不解析 HTML），最多 2 行，超出省略并 title 显示全文不从 summary 里拆出旧/新状态或回信主题；回信正文不显示、不可展开
actor name + role名字 + 角色小标签；系统事件不显示角色没有头像、邮箱
at相对时间（<1 天：“N 分钟/小时前”；昨天 HH:mm；更早 M月D日 HH:mm）；悬停/聚焦显示绝对时间 PT；<time datetime>按 PT 日期分组；接口按时间正序返回，前端倒序显示（最新在上）
分页先显示最新 10 条，“显示更早的 N 条”每次 +10纯前端切片；N = 总数 − 已显示
