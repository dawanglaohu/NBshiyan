Theme B (.theme-premium: #121214 / gold #D4AF6A, gold buttons with #121214 text) only when the product is a gift box or wine box — frame ⑨. Russian frames use the longest strings we ship. Route: /[locale]/products/{slug}/customize. Steps: 1 Color → 2 Logo → 3 Size (regular box types only; hidden for fixed shapes, progress becomes 3 segments) → 4 Review & share.

Interaction spec for front-end

AreaRule
LayoutTop bar 56px (Back-to-product 44×44, product name ellipsised, Share 44×44). Progress 52px. Viewer fixed 300px high (min 260px on 360-wide/short screens), sticky under top bar while the step panel scrolls. Panel scrolls; its padding-bottom = var(--bar-h) + var(--fab-clearance) so the last control is never under the bar, FABs or cookie bar.
Sticky action barposition:fixed; bottom:var(--consent-h,0px) + env(safe-area-inset-bottom); height 76px. Cookie bar sits below it (bar rises with it, never overlaps). On this route the chat / WhatsApp FABs lift to bottom: calc(var(--consent-h) + var(--bar-h) + 12px); --fab-clearance (136px + cookie bar height, from #183) stays the page bottom padding. When cookie bar closes, --consent-h → 0 and everything drops with transform (--dur-base, --ease-out).
ProgressSegmented bar, one segment per step; label row "Step 2 of 4 · Logo" (RU «Шаг 2 из 4 · Логотип»). <nav aria-label="Customizer steps"><ol>, current item aria-current="step". Completed segments are tappable (44px tall hit area over 4px line) to jump back; future segments are not tappable.
Next / BackBack = ghost, Next = coral primary (flex:1). Step 1 shows "Back" disabled-hidden: bar has only Next. Last step: Next becomes "Request a quote" / «Запросить расчёт», secondary "Copy link" moves into the panel. Next never disables silently: if a step is invalid (e.g. size out of range), Next stays enabled, tapping scrolls to the error and focuses it (aria-invalid, aria-describedby). Logo is optional ("Skip" = Next).
Choices keptAll state in one store ({color, logo:{fileId,scale,pos}, size:{l,w,h,unit}, step}), mirrored to the URL query (?step=2&c=coral…, history.replaceState) and sessionStorage. Back, step jump, browser back and reload restore every choice; the uploaded logo is not re-uploaded. Frame ⑦ shows Back to Color with previous choice kept and a confirmation chip "Your choices are saved".
SwipeHorizontal swipe on the panel only (never on the viewer — the viewer uses drag to rotate) switches step: threshold 64px or velocity > 0.4px/ms, vertical intent (>30°) cancels. Swipe is an extra, buttons are the primary path. Disabled while a number input or slider is focused.
Step transitionPanel content: outgoing opacity 1→0 + translateX(0→∓var(--dist-md)), --dur-base --ease-in; incoming opacity 0→1 + translateX(±var(--dist-md)→0), --dur-base --ease-out. Transform/opacity only. Reduced motion: tokens give --dist-md 0 and --dur-base 120ms → plain 120ms fade. After switch, focus moves to the step heading (tabindex=-1) and a polite live region announces "Step 3 of 4, Size".
3D viewerAuto-rotate 0.15 rad/s around Y, starts after first frame rendered; pauses on touch, resumes 3s after last interaction; pauses when off-screen (IntersectionObserver) or tab hidden. One-finger drag = rotate, pinch = zoom, two-finger never hijacks page scroll (touch-action: pan-y on viewer except during an active rotate gesture). Reduced motion: no auto-rotate, static 3/4 view. Tools (44×44): reset view, size reference toggle (step 3), fullscreen.
Viewer statesPlaceholder: product poster image (from 3D poster set) shown instantly at the same framing, with "Loading 3D… 42%" pill; skeleton shimmer only if poster is missing (shimmer off in reduced motion). Swap poster → canvas with opacity crossfade --dur-slow when first frame is ready. Steps are usable while loading (choices apply when model arrives). Slow (>6s): text "Still loading — you can keep choosing". Error (WebGL unavailable / load failed): poster stays, overlay card "3D preview unavailable" + "Try again" (44px) + "Your choices still apply to the quote". Choices are never blocked by the 3D.
Size stepL × W × H steppers (44×44 −/+ buttons, value is input inputmode="numeric"), unit toggle mm / in (converts, rounds to 1mm / 0.1in). Range per box type from product data; error text below the field. Size reference: silhouette next to the box, same scale, drawn in an inline SVG (2D, on top of viewer) with dimension callouts in the chosen unit. Reference chips: Hand (≈190mm), A4 sheet (210×297mm), Wine bottle 0.75 L (≈300mm); default = closest in height to the box. Reference changes are not part of the quote.
Focus & targetsAll controls ≥44×44. Focus ring = #120: :focus-visible → --focus (2px bg gap + 2px --accent-text; gold on theme B), no transition. Swatches have text names (aria-label, and the selected name is shown under the row).
Theme BOnly for gift box / wine box products: wrap the page in .theme-premium. Primary = gold #D4AF6A with #121214 text; ghost = #F2E9D8 text on #2E2C28 border.

变量：悬浮按钮 bottom = var(--consent-h) + var(--action-bar-h) + 12px（--action-bar-h 由前端新增）。
